1注文はどこから入ってくる?

HiBoardには5つの入り口から注文が入ってきます。どこから来ても、最終的には全部「📥 受注候補の取り込み」タブか「➕ 新規案件」に集まります。

番号の頭文字で入り口が分かります。 W- はホームページのご注文フォーム、T- はチームの追加注文、P- は取引先からの加工依頼です。 お客様や取引先から「受付番号は W-12 です」と電話が来たら、「受注候補の取り込み」タブでその番号を探せば内容が見られます。

取引先(P-)の依頼は2種類あります

  • 追加案件 … 取引先が発行した指図書の写真・PDFが添付されています。加工の詳細はその指図書を見てください。
  • 新規案件 … 加工内容が画面にひととおり入力されています。
「■紹介」が書いてあったら(紹介キャンペーン)。 受注候補のメモに 「■紹介: 長泉AMiGOS(チーム) からのご紹介」 のように出ていたら、 ご紹介経由のお客様です。誰の紹介かは自動で表示されますので、そのまま対応を進めてください。 ご成約(ご入金)まで進んだら、紹介してくださった方へ特典をお渡しします(内容は久保田社長に確認)。
「※未登録のコードです」と出ている場合は、当社が発行していないコードが入力されています。 お客様に確認のうえ、久保田社長へ共有してください。

2朝いちばんにやること(注文の取り込み)

🕘 使うタイミング: 出社したとき、あとは午後にもう一度

① 赤いバッジを確認する

HiBoardを開いて、上のタブに「📥 受注候補の取り込み 2」のような赤い数字が出ていたら、まだ確認していない注文がその件数あるという意味です。まずここをクリックします。

※ 赤い数字が出ていなければ、新しい注文はありません。

TODOリストにも自動で入ります。 新しい注文が届くと、社員用のTODOリスト(Googleスプレッドシート)にも「対応してください」というタスクが1件、自動で追加されます。 ただしお客様の名前が読み取れなかったLINEの問い合わせは、1日1行にまとめて入ります。まとめて入っていた日は、HiBoardのこの画面で中身を確認してください。

② 届いた注文を「案件」にする

カードをクリックすると、内容の確認画面が開きます。やることは3つだけです。

  1. 左側にお客様からの実際のやりとり・注文内容が表示されるので、目を通す
  2. 右側の入力欄(案件名・顧客名・納期・加工種別・数量など)を確認し、足りないところを埋める・間違いを直す
  3. 下の「案件として登録」ボタンを押す → これで正式な案件になります
注文ではなかった場合は? 「ただの質問だった」「いたずら」など案件にする必要がないものは、「却下」ボタンを押してください。消えて、赤いバッジの数字も減ります。
注意: 「案件として登録」を押すまでは、まだ案件になっていません。カードのまま放置すると、スケジュールにも一覧にも出てきません。必ずその日のうちに登録か却下をしてください。

③ LINEやメールの文章から取り込む(コピペ)

AIが自動で拾えなかったやりとりや、メールで来た注文は、こちらを使います。

  1. LINEやメールの本文をコピーする
  2. 「受注候補の取り込み」タブの下半分にある「テキストから案件情報を抽出」の枠に貼り付ける
  3. 「🔍 テキストから抽出」を押す → 案件名・顧客名・数量・納期などをAIが自動で読み取ります
  4. 読み取った内容を確認・修正して登録

※ 長い雑談まじりの文章でも大丈夫です。うまく読み取れなかった項目は手で直してください。

④ 電話・口頭で受けた注文

一覧ビューの「➕ 新規案件」ボタンから手入力します。案件名・顧客名・受付日・納期・連絡経路・加工種別・数量が必須です。連絡経路は「電話」を選びます。

3案件を進める(ステータスの切り替え)

🕘 使うタイミング: 作業が一段階進むたび

案件には8つの状態(ステータス)があります。今どこまで進んでいるかを、みんなが見て分かるようにするためのものです。

ステータスどういう状態?次に進めるタイミング
受注前見積り中・お客様の返事待ち正式に「お願いします」と言われたら
受注確定注文が確定した生地・資材の手配が済んだら
生産待ち資材は揃った。作業の順番待ち製版・データなど準備が終わったら
準備完了すぐ作業に入れる状態実際に加工を始めたら
生産中プリント・刺繍の作業中加工が終わったら
検品仕上がりをチェック中検品OKで梱包まで済んだら
納品待ちお渡し・発送を待つだけ実際に納品したら → 第5章へ
納品済み完了。一覧からは消えます—

ステータスの変え方(2通り)

  • カンバンビューでドラッグ … 「🎯 カンバンビュー」タブを開き、案件カードをつかんで隣の列に動かすだけ。いちばん速いです。
  • 編集画面から変える … 一覧ビューの「✎ 編集」を押して、ステータス欄を選び直して保存。
なぜこまめに変えるの? 理由は2つあります。
  1. スケジュールボードは「受注確定・生産待ち・準備完了・生産中」の案件だけを作業予定として拾います。ステータスが古いままだと、割り振りに出てこなかったり、終わった仕事が残り続けたりします。
  2. 取引先(八木繊維さんなど)の納期確認ページに、そのまま反映されます。取引先は自分の案件が今どの段階かを専用ページで見ています。ここを更新しておけば「上がりはいつ?」の電話が減ります。

※ 取引先側には社内の細かい工程はそのまま出ず、受付済み → 製作中 → 検品・出荷準備中 → 納品済みの4段階にまとめて表示されます。

4今週の作業を割り振る(スケジュール)

🕘 使うタイミング: 週のはじめ、あとは毎朝の確認で

ヘッダーの「🗓️ スケジュール」から開きます。縦に従業員、横に曜日が並んだ表です。

① 自動で割り振ってもらう

  1. 「🤖 今週を自動割り当て」ボタンを押す(1日分だけなら、その曜日の「🤖 自動割当」)
  2. 誰がどの作業をするか、AIが提案を出します
  3. 右側の「📝 提案確認」パネルに提案が並ぶので、内容を見て承認する
提案は自動では反映されません。 「提案確認」で承認して初めて予定になります。バッジに数字が出ていたら未確認の提案がある印です。

② 手で割り振る・直す

表のマス目をクリックすると、その人のその日の予定を直接編集できます。自動割り当ての結果を微調整するときもここです。

③ 一緒に見ておきたい2つの表

  • 🗂️ 準備項目リスト … その週にやっておくべき製版・データ作成などの一覧。作業当日に「版がない!」を防ぎます。
  • 📈 案件別 消化率 … 予定した時間に対して実際どれだけ進んだか。遅れている案件が一目で分かります。

4.5デザイン案件を回す(デザイン案件全般)

🕘 使うタイミング: デザインが絡む案件を受けてから請求するまで（担当: 山本さん）

デザイン担当は制作に専念してもらうため、お客様や外注先とのやりとり・書類はオペレーション担当がまとめて引き受けます。 その進み具合を管理するのがヘッダーの「🗂 デザイン案件全般」画面です。

まず、この画面に載せる案件を選びます

案件を登録するとき(新規案件・受注候補の確定のどちらでも)、上のほうにある 「🗂 デザイン案件全般として管理する」にチェックを入れた案件だけがこの画面に出ます。 チェックを忘れると画面に出てこないので、デザインを起こす案件では必ず入れてください。

※ 後から気づいた場合は、案件の「編集」からチェックを入れれば追加できます。

案件には2つの進行タイプがあります

案件登録の「デザイン案件全般として管理する」の下で選びます。

  • 加工まで（標準） … 衣類など。下の7段階をすべて通ります
  • 📄 紙媒体・入稿で完了 … ポスターなど。デザイン担当の制作から始まり、 お客様の最終OK後にデザイン担当が入稿したら自動で「請求」へ進み、 請求書を発行して完了です（検品・納品は通りません）。カードに 📄 のバッジが付きます

※ 紙媒体タイプは準備項目「入稿完了」が自動で付きます。デザイン担当がマイスケジュールボードで これを完了にすると案件が「請求」へ進み、請求カードの「請求済み・完了にする」チェックで締めます。

紙媒体はさらに2種類あります

「📄 紙媒体・入稿で完了」を選ぶと、出どころを選ぶボタンが出ます。

  • HiYOSHi からの依頼 … 弊社からデザイン担当へ依頼している紙媒体
  • 🔶 CARVE で受けている案件 … デザイン担当がCARVEで受けている案件。 イレギュラー案件なので、ボード上では紫の枠が付いて目立つようになっています

バトンタッチは自動で通知されます

担当が切り替わると（制作を渡した・初稿が提出された・修正で戻した など）、 Google Chat の「デザイン案件」スペースに自動で通知が届きます。 そのため「ステータス変更しました」「完了しました」の連絡は不要です。 通知が来ていない=まだ自分の番ではない、と考えて大丈夫です。

後から載せる・外す

  • 載せる … 一覧ビューのその案件の行にある「🗂 全般へ」ボタンを押す
  • 外す … この画面のカード右上の「✕」を押す（一覧ビューの「🗂 全般から外す」でも同じ）
「✕」を押しても案件そのものは消えません。 この画面に出さなくなるだけで、一覧ビューにはそのまま残り、生産の進行にも影響しません。 案件そのものを消したいときは、一覧ビューの「編集」から削除してください。
この画面から新しい案件も登録できます。 左上の「➕ 新規案件」を押すと、 「デザイン案件全般として管理する」にチェックが入った状態で登録画面が開きます。 保存するとこの画面に戻ってきます。

アイテム名を入れておく

案件登録の「基本情報」にアイテム名の欄があります （例: ドライTシャツ / az50018 半袖ポロシャツ）。 入れておくと、カードに🏷 のタグで表示され、何を作る案件かが一目で分かります。

※ ホームページのご注文フォームから入った案件は、注文時のアイテム情報が自動で表示されるので入力は不要です。

登録した後で内容を直したいとき

カードを押して開いた画面の「✎ 案件を編集」から、 納期・数量・加工内容・アイテム名などすべての項目を編集できます。 保存するとこの画面に戻ってきます。

案件は7つの段階で進みます

  • ① ブリーフ・ラフ … 依頼内容を確定させ、デザインラフを添えてデザイン担当へ渡す
  • ② 制作 … デザイン担当が初稿を作る
  • ③ 確認 … 初稿をお客様に見てもらう
  • ④ 入稿・製造 … 外注へ入稿、または社内で加工
  • ⑤ 請求 … 請求書を発行する
  • ⑥ 検品 … 仕上がりをチェックする
  • ⑦ 納品 … お渡し・発送する。済んだらカードのチェックボックスを入れて完了

段階の移動はドラッグ&ドロップで

カードをつまんで別の列へ落とすだけで段階が変わります。 前にも後ろにも動かせるので、修正が必要になったときは「確認」から「制作」へ戻すなど、 実際の流れに合わせて自由に動かしてください。

※ カードを押すと詳細画面が開き、そこのボタンからでも段階を変えられます。

自動で進むところ

  • デザイン担当が準備項目の「初稿提出」を完了すると ②→③ へ
  • デザイン担当が「外注用デザインデータ作成」を完了すると ③→④ へ
  • 一覧ビューで「📦 納品済み」を押すと ⑦納品 へ

※ 上記以外はドラッグ&ドロップで動かします。完了にするのは納品カードのチェックボックスです。

③確認は4つのステップで進みます

カードを開くと「確認の進み具合」が出ます。やりとりが進むたびに次へ切り替えてください。

  1. お客様へ確認連絡 … 初稿をお客様へ送る
  2. お客様の返事待ち … 送った後、返事を待つ
  3. 位置・大きさの調整 … 返事をもとにプリント位置やサイズを直して、もう一度お客様へ確認
  4. 最終確認の返事待ち … OKをもらったら「入稿・製造」へ進める

1と3（自分が動く番）は「今日やること」に出ます。 2と4（お客様の返事待ち）は普段は出ませんが、 返事がないまま7日を過ぎると催促として自動で戻ってきます。

デザインラフの渡し方

デザイン担当はリモート勤務で会社のNASを見られません。ラフは案件のカードを開いて その場に添付してください(1ファイル15MBまで・一度に5件まで)。 添付するとデザイン担当のマイスケジュールボードに「🖼 ラフ」のリンクが出て、そこから開けるようになります。

デザイン担当の画面に出る作業

この画面に載せた案件の作業カードは、「入稿・製造」より前の段階のあいだだけ デザイン担当のマイスケジュールボードに出ます。 「入稿・製造」へ進めると、その案件の作業はデザイン担当の画面から自動で消えます （入稿が終われば、もうデザイン担当の手を離れているためです）。 差し戻して「確認」などに戻せば、また出てきます。

5納品したとき

🕘 使うタイミング: お客様にお渡し・発送した日

  1. goodnoteの指示書をPDFに書き出して、その案件のNASフォルダに保存する(Freeeの見積書・請求書PDFも同じフォルダへ)
  2. 一覧ビューでその案件の「📦 納品済み」ボタンを押す
  3. 納品日(今日の日付が最初から入っています)を確認
  4. 発送方法を選ぶ … 来社納品 / 発送 / 持参納品
  5. 納品者(担当した人)を選ぶ
  6. 「指示書PDFを保存した」のチェックを入れて保存

お渡しのときに、ひとこと添える

納品物には「クチコミ依頼カード」を1枚同梱してください。お渡し・発送のときに 「仕上がりに問題がなければ、よろしければGoogleに一言いただけると嬉しいです」と 声をかけていただけると、書いてもらえる確率がぐっと上がります。

クチコミは「お願い」まで。特典と交換しないでください。 Googleは特典・割引と引き換えのクチコミを禁止しています。 「クチコミを書いてくれたら○○します」と言ってしまうと、集めたクチコミがまとめて消されたり、 会社のGoogleページ自体が止められたりすることがあります。 お願いするのはOK、見返りを約束するのはNGと覚えてください。 (紹介キャンペーンの特典は別の制度なので、そちらは今までどおりで問題ありません)
不満そうなときは、その場でお聞きする。 カードの裏にも「気になった点はクチコミの前に直接お聞かせください」と書いてあります。 お客様が渋い反応のときは無理に勧めず、その場で内容を伺って久保田社長へ共有してください。
一覧から消えても大丈夫です。 納品済みにすると案件一覧からは見えなくなりますが、データは消えていません。ヘッダーの「📦 納品履歴」からいつでも見返せますし、次章のリピート注文にも使います。
準備項目のチェックが残っていても大丈夫です。 納品済みにすると、その案件の準備項目はチェックが付いていなくても自動で完了扱いになり、スケジュールの「準備項目リスト」やデザイン担当者のマイスケジュールボードから消えます。納品したものを毎回チェックし直す必要はありません。
なぜ指示書PDFをNASに入れるの? 納品後に「あの案件どうだったっけ?」となったとき、納品履歴の「📁 フォルダ」ボタンでその案件の指示書・入稿データをブラウザからすぐ見られるようにするためです。案件にFreee見積書/請求書リンクを貼っておけば、「📄 見積書」「📄 請求書」ボタンからFreeeの画面も1クリックで開けます。

6同じチームから「また同じものを」と言われたら

🕘 使うタイミング: 前と同じ内容の追加注文・リピート注文

ゼロから入力し直す必要はありません。「📦 納品履歴」から複製できます。

  1. ヘッダーの「📦 納品履歴」を開く
  2. 検索窓に顧客名や案件名を入れて、前回の案件を探す(過去すべてが対象です)
  3. 「↻ 再注文」ボタンを押す
  4. 今回の納期と数量を入れて「複製して登録」
引き継がれるもの ✅引き継がれないもの ⚠️(入力し直し)
顧客名 / 加工内容 / プリント箇所 /
NASのデザインフォルダ		 担当者 / 作業計画(スケジュール) /
名簿(選手名・背番号)

複製した案件は「受注前」の状態で作られます。内容を確認して、担当者の割り当てなどを設定してください。

紹介コードをお渡しするとき(紹介キャンペーン)

お客様から「知り合いを紹介したい」と言われたら、⚙管理 →「🎁 紹介コード発行」で コードを発行します。種別(チーム / 個人)を選んで名前を入れるだけで、 HY-T01(チーム)や HY-P001(個人)のようなコードが自動で決まります。

  • 発行したコードを紹介カードに書いてお渡しします
  • お客様はその番号を紹介ページで入力すると、自分の特典と「お知り合いに送るリンク」を見られます
  • そのリンクから注文されると、受注候補に紹介者の名前が自動で表示されます
  • 発行すると、スプレッドシートの「紹介コード台帳」タブにも自動で1行増えます
種別は後から変えられません。 特典の内容が変わるため、発行するときに チームか個人かを確認してください。渡した相手が変わった・使わなくなった場合は 「無効化」を押すと、そのコードでは紹介ページを開けなくなります。

紹介コード台帳(スプレッドシート)

コードを発行すると、社員TODOリストの「紹介コード台帳」タブに 1行が自動で増えます。埋まるのは紹介コード・紹介者名・種別・発行日・メモの5つです。 紹介カードを書くときや、お客様から「私のコード何番だっけ?」とお電話をいただいたときは、 HiBoardを開かなくてもこのシートで確認できます。

チェック欄は今までどおり手で付けてください。 「カード渡し済」「紹介先」「成約日」「特典 処理済」はHiBoardは触りません。 運用の記録なので、これまでと同じように手で埋めていってください。
  • 台帳に載るのはコードをお渡しした方の情報だけです。ご紹介先のお客様のお名前は入りません
  • シートの行を直しても、HiBoard側のコードは変わりません(正しいのは常にHiBoardです)
  • 台帳に見当たらないコードがあるときは、「📋 台帳へ全件送信」を押すと入れ直せます。 既にある行は増えないので、何度押しても大丈夫です

7困ったときのQ&A

ヘッダーのボタンが減った。従業員の登録などはどこ?
毎日使うもの(スケジュール・デザイン担当者の予定・納品履歴・顧客台帳・使い方)だけを表に出し、設定や発行の操作は右端の「⚙ 管理」にまとめました。押すと、担当者マスタ・従業員マスタ・チーム/取引先/デザイナーのリンク発行・制作実績の登録が出てきます。スマホでは「☰ メニュー」を押すと同じものが開きます。
デザイン担当者が今どれをやる予定なのか見たい
ヘッダーの「🎨 ◯◯さんの予定」(担当者の名前が入ります)を押すと、デザイン担当者のマイスケジュールボードがそのまま開きます。専用URLを控えておく必要はありません。本人が予定を動かすと社内のスケジュールボードにも反映されるので、どちらから見ても同じ内容です。
※ まだデザイナーリンクを発行していない場合は、発行画面(⚙ 管理 → 🎨 デザイナーリンク発行)が開きます。
「担当者マスタ」と「従業員マスタ」は何が違う?
担当者マスタは案件の窓口になる人(その案件を誰が見ているか)、従業員マスタは実際に作業する人です。従業員マスタの人は勤務パターンと加工別の生産性を持ち、スケジュールボードの割り当て対象になります。
入力画面(新規案件)の項目が折りたたまれている
入力する順番どおりに「1. 基本情報」〜「5. 作業内容・メモ」に分けました。見出しをクリックすると開閉できます。「4. データと書類」(NASフォルダ・Freeeリンク)は使うときだけ開けばよいので、最初は閉じています。保存ボタンは画面の下に固定されているので、どこまでスクロールしても押せます。
一覧の行が赤や黄色になっているのは何?
納期が近い・過ぎている案件です。日付の横に「納期超過」「3日以内」「7日以内」と文字でも出るようになりました。色の意味は一覧の上の凡例にも書いてあります。
お客様から「W-12」「T-5」「P-3」と番号を言われた
Webフォーム(W)・チーム追加注文(T)・取引先の加工依頼(P)の受付番号です。「受注候補の取り込み」タブで該当のカードを探すと内容が確認できます。すでに案件登録済みの場合は、案件のメモ欄にも同じ番号が記録されています。
取引先から「あの案件、今どうなってる?」と聞かれた
取引先には進行状況を見られる専用ページをお渡ししています。HiBoardでステータスを最新にしておけば、そちらで確認していただけます。急ぎでなければ「専用ページでご確認いただけます」とご案内してください。
赤いバッジの数字が減らない
「案件として登録」か「却下」のどちらかを押すまで残ります。開いて閉じただけでは減りません。
画面が古いままの気がする
ブラウザを一度閉じて開き直してください。それでも直らないときは、パソコンの再起動をお試しください。
案件が一覧に見当たらない
納品済みにすると一覧から消えます。「📦 納品履歴」を確認してください。また、一覧上部の絞り込み(ステータス・担当者など)が効いている可能性もあります。
「あのお客様、前は何を頼んでくれたっけ?」を調べたい
ヘッダーの「📇 顧客台帳」を開いて顧客名で検索してください。そのお客様の全案件(進行中含む)が一覧になり、各案件から指示書PDFなどの📁 フォルダ、Freeeの📄 見積書・請求書、↻ 再注文まで辿れます。担当窓口や注意点を書き残す顧客メモもこのページにあります。
「よく取引しているお客様」「たくさん作っているお客様」を知りたい
「📇 顧客台帳」の並び替えで「取引案件数」「取引数量」「最終納品」を選び、順序で多い順(新しい順)・少ない順(古い順)を切り替えてください。加工種別のプルダウンを使うと「帽子刺繍のお客様だけ」のように絞り込めます。条件は組み合わせて使えます(元に戻すときは「条件をクリア」)。
過去案件で「何をどのくらい加工したか」を確認したい
顧客台帳または「📦 納品履歴」で、案件名をクリック(または「🔍 詳細」ボタン)してください。加工種別・数量・プリント箇所・サイズ別の枚数内訳・作業内容がまとめて表示され、同じ画面から指示書PDF(案件フォルダから自動で拾います)と見積書・請求書も開けます。指示書が出てこないときは、その案件のNASフォルダにPDFが保存されていない可能性があります。
スケジュールに案件が出てこない
ステータスが「受注前」「検品」「納品待ち」の案件は、スケジュールの対象外です。作業が必要な段階なら、ステータスを「受注確定」以降に進めてください。
間違えて登録・却下してしまった
登録した案件は「✎ 編集」で直せます。却下してしまった場合は元に戻せないので、お客様とのやりとり(LINE等)を見ながら「➕ 新規案件」で入力し直してください。

分からないことがあれば、遠慮なく社長または担当者に聞いてください。
