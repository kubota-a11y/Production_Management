# AI利用ルール(社内共通) ─ 案

三浦さん・山本さんが AI を使うときの共通ルール。**対象は Claude と Gemini の両方。**
配布用のA4・1枚版は `AI利用ルール_社内共通.html` / `.pdf`(このフォルダ)。

## このルールが必要な理由

Claude Code 側の禁止事項は `.claude/settings.json` と個人別の `CLAUDE.md` で**システム的に止められる**。
一方、**チャット(claude.ai)や Gemini は設定で縛れない**ため、運用ルールで守る必要がある。

現状(2026-08-25 時点):

- **三浦さん** — AIは Gemini のみ使用。Claude Code を使うかは**ヒアリング中**
- **山本さん** — Claude のチャット中心＋最小構成の Claude Code
- **HiBoard の中身を作っているのは久保田 + Claude Code。** 三浦さん・山本さんは「使う側」

## 1. アカウント ─ 必ず会社のアカウントで使う

| 使うもの | 入力した内容の扱い |
|---|---|
| **Claude チームプラン(Standard)** | **入力した内容・AIの回答が、AIモデルの学習に使われない**(法人向けの商用利用規約が適用されるため) |
| **Gemini(会社のGoogle Workspace)** | 会社アカウントで使う限り**業務向けの契約が適用される**。個人のGoogleアカウントで開いたGeminiは対象外 |
| 個人の無料・Proアカウント／自分のスマホのアプリ | **会社の仕事に使わない。**設定によっては**入力内容が学習に使われる** |

- ログイン情報を他人に貸さない。退職・異動のときは席を返却する。
- 規約は改定されることがある。**契約時と年1回、最新の規約を確認する(久保田)。**

## 2. 入れてよい情報 / 入れてはいけない情報

**判断に迷ったときの目安：「これを社外の業者さんにメールで送れるか?」送れないものは入れない。**

| 判断 | 情報の種類 |
|---|---|
| ○ 入れてよい | 案件の内容、加工の種類・枚数・納期、**お客様の会社名・お名前・電話番号・住所**、社内の資料・議事録、HiBoardの画面の見え方、文章の下書き |
| ○ 入れてよい | **自社の価格・原価・仕入単価**(見積書づくりなど、業務に必要な範囲で) |
| **× 入れない** | パスワード、APIキー、各種サービスのログイン情報 |
| **× 入れない** | マイナンバー、口座番号、生年月日 |
| **× 入れない** | 従業員の給与・評価・人事に関する情報 |
| **× 入れない** | 取引先から「社外秘」と示された資料・契約条件 |
| **× 入れない** | お客様の顔が写っている写真(掲載許可が取れているものを除く) |

## 3. 出す前に、必ず人が確認する

AIが作ったものを、**そのまま外に出さない。**

| 出すもの | 確認する人 |
|---|---|
| SNS投稿(KRATVSのInstagramリールなど) | **社長**(投稿前に必ず) |
| 協賛・取引条件の提示 | **社長**(条件を伝える前に必ず) |
| ホームページに載せる文章・制作実績 | **社長**(お客様の掲載許可も必要) |
| お客様・取引先へ送るメール、見積書 | 山本さん → **三浦さん** / 三浦さん → 自分で確認 |
| 社内資料・議事録のまとめ | 作った本人が**原本と突き合わせる** |

## 4. AIは間違える ─ 数字と事実は自分で確かめる

実際に起きた例(2026-08-24):

- KRATVSのカタログを確認させたところ、**AIは「152ページ」と認識したが、実際は18ページ**だった。
- 議事録と録音の文字起こしで**「大人ネイビーのインク色」が食い違っていた**。AIは食い違いを指摘できるが、**どちらが正しいかを決めるのは人**。

**金額・数量・納期・サイズ・品番は、AIの出力をそのまま信じない。必ず原本で確認する。**

## 5. HiBoard(生産管理)のこと ─ 誰に聞くか

| こと | 担当・相談先 |
|---|---|
| HiBoardを日々**使う**(受付・案件登録・進捗入力) | 三浦さん・山本さん |
| 画面の**操作**が分からない | 操作説明資料 → それでも不明なら三浦さん |
| HiBoardの**中身を作る・直す**(仕組み・不具合・機能追加) | **久保田**(Claude Codeで開発) |
| 「動きがおかしい」「こう変えたい」 | **久保田へ。**自分で直そうとしない。**「どの画面で・何をしたら・どうなったか」**を書いて渡す |

- Claude Code で**ファイルを直接触る場合のみ**: 開発ルール(`CLAUDE.md`)を必ず読む／**本番反映は久保田の承認後**／山本さんは本番反映を行わない。

## 6. 困ったとき

| 状況 | 相談先 |
|---|---|
| 仕事の進め方の判断 | 山本さん → **三浦さん** / 三浦さん → **久保田** |
| この情報をAIに入れてよいか判断がつかない | **入れる前に久保田** |
| 誤って入れてはいけない情報を入れてしまった | **すぐ久保田に報告**(隠さない。早いほど手が打てる) |
