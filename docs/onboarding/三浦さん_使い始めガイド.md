# Claude 使い始めガイド(三浦さん用)

Claudeは初めてとのことなので、**受付業務での壁打ちから**始める。
リポジトリを使う作業(HiBoardの切り分け・週次お知らせ)はPhase 2から。

---

## Claudeに入れていいもの・いけないもの

**詳しくは `AI利用ルール_社内共通.pdf` に従う。**要点だけ:

- ○ 案件の内容、お客様の会社名・お名前・連絡先、自社の価格・原価、社内資料・議事録
  (会社のTeamアカウントなので、**入力内容はAIの学習に使われない**)
- × **パスワード・APIキー・ログイン情報**(どんな場面でも)
- × マイナンバー・口座番号・生年月日
- × **従業員の給与・評価・人事に関する情報**
- × 取引先から「社外秘」と示された資料

判断の目安:**「これを社外の業者さんにメールで送れるか?」**送れないものは入れない。

## Phase 1:受付業務の壁打ちから

コピペしてそのまま試せる例。自分の言葉に置き換えてOK。

### 見積・受付

```text
チームユニフォーム30着(昇華プリント・背番号と名前入り)の見積を作ります。
お客様に確認すべき項目を、抜けが無いようにリストにしてください。
```

```text
以下のお客様からの問い合わせに対する返信の下書きを作ってください。
丁寧すぎず、簡潔に。納期は確定しておらず、確認して折り返す旨を伝えたい。

（問い合わせ本文を貼る）
```

### 議事録からのTODO抽出

```text
以下の議事録から「次のステップ」を読み取り、社内担当分だけを抽出して
担当者・期限・内容の表にしてください。社長担当分は除いてください。

（議事録を貼る）
```

### 山本さんのフォロー

```text
山本さんから「HiBoardの案件登録で必須項目が分からない」と相談がありました。
新人にも分かるように、確認手順を3ステップで整理してください。
```

### 考えの整理

```text
受付から加工指示までの流れで、いま手戻りが多いのは
「お客様の希望サイズの確認漏れ」です。
原因の候補と、防ぐ仕組みの案を出してください。
```

## Phase 2:HiBoardを扱えるようになったら

リポジトリを入れたあとに使えるようになるもの。

### 不具合の一次切り分け

```text
HiBoardのスケジュールボードで、案件カードをドロップしても
担当者に割り当てられないという報告がありました。
考えられる原因を、設定・データ・コードの3方向から絞り込んでください。
```

**ここでの目標は「自分で直す」ことではなく、「原因を特定して久保田に渡す」**こと。
「どこが悪いか」まで分かった状態で上がってくれば、久保田の対応時間が大幅に減る。

### 週次「社内システムお知らせ」

```text
/weekly-news
```

前号以降のgitの変更履歴から、社員向けのA4資料を自動生成する。
**生成された内容は必ず自分で読んで、事実と合っているか確認してから配る。**

## 使いこなすコツ

- **1回で完璧を求めない。**出てきた答えに「もっと短く」「この部分を詳しく」と続けて直させる
- **背景を伝えるほど良い答えが出る。**「誰に」「何のために」を最初に書く
- **AIは間違える。**特に数字。実際に2026-08-24、カタログのページ数を「152ページ」と誤認した例がある(実際は18ページ)。**数字と事実は必ず自分で確かめる**

---

## やってはいけないこと

- **本番への反映は行わない。**三浦さんのPCはサーバー用PCと切り分けられており、`update.bat` は実行できない設定になっている。反映が必要なら**久保田へ連絡する**
- `git push` は確認ダイアログが出る。**pushしたら必ず久保田へ連絡する**(連絡が無いと、次の反映時に意図しない変更が本番へ出る)
- AIが作ったものを**そのまま外に出さない**。メール・見積は自分で確認してから送る

## 困ったとき

| 状況 | 対応 |
|---|---|
| Claudeの使い方が分からない | まずClaude自身に聞く(「〜はどうやるの?」) |
| HiBoardの仕様・機能追加の判断 | 久保田 |
| ログインできない・エラーが出る | 久保田 |
| 本番に反映したい | **久保田へ連絡** |
| 「使用上限」の表示が出た | 時間を置けば戻る。**故障ではない**。頻発するなら久保田に報告 |

## 上限について

三浦さんのシート(Standard)には使用量の上限がある。
5時間ごとの枠と週の枠があり、使い切ると一時的に使えなくなるが、時間が経てば自動で戻る。
上限に当たった日をメモして久保田に伝えてもらえれば、プランの調整を検討する。
