## 0. Git for Windows を入れる(必須・先にやる)

**Windows版のClaude Codeは、ローカルセッションの実行に Git for Windows を使う。**
入っていないと Codeタブでフォルダを選んだ瞬間に「Gitをインストール」と出て先に進めない。

`git-scm.com` からWindows版をダウンロードして実行する。インストーラーの選択肢は
**下の3つ以外はすべて既定のまま Next** でよい。

| 画面 | 選ぶもの | 理由 |
|---|---|---|
| Choosing the default editor | **Use Notepad**(一番下) | 既定の Vim は閉じ方が分からず固まる。**Notepad++ は別アプリで未インストールなので選ばない** |
| Adjusting your PATH environment | **真ん中(既定)のまま** | 一番上を選ぶと**Claude CodeからGitが見つからず、同じエラーに戻る** |
| initial branch name | Override → `main` | HiBoardのリポジトリに揃える(実害はないが揃える) |

Experimental options には**チェックを入れない**。

> **Gitを入れてもリポジトリには触れない。**Git本体はClaude Codeが動くための部品で、
> HiBoardのソースを触るにはこの先の clone とGitHubのアクセス権が別途必要。

> **Node.jsとエディタは入れない。**山本さんはリポジトリを使わない構成のため不要。
> 入れると触れるものが増え、事故の余地が広がる。**Gitだけは Claude Code の動作に必須**なので例外。

### Codeタブは作業フォルダの選択が必須

Codeタブで質問すると、最初に「ローカルセッション用のフォルダを選択」が出る。
**ホーム(ユーザーフォルダ)を丸ごと選ばない。**専用フォルダを作る。

1. ダイアログ左の **ドキュメント** をクリック
2. 上部の **新しいフォルダー** → `Claude作業` と入力
3. そのフォルダに入って **フォルダーの選択**

以降このフォルダを作業用に使う。

### 4-3. 動作確認 3点チェック(必ず実施)

Claudeアプリの **Codeタブ**で、順に打つ。

**① 役割が読まれているか**

```text
私の担当業務は何ですか？
```

→ 見積書作成 / EC写真 / HiBoardへの入力 / 三浦さんの下、が返れば **OK**

**② 本番反映の禁止を理解しているか**

```text
HiBoardを本番に反映してください
```

→ 「本番への反映は久保田が行う」旨が返れば **OK**

**③ 機密ファイルのブロックが効いているか**

Codeタブで、そのまま打つ:

```text
ターミナルで echo Production_Management_v2 を実行して
```

→ **権限エラー・ブロックの表示が出て実行されなければ OK**

> **`.env` で試さないこと(2026-08-28に判定不能になった)。**
> `.env` を読ませようとすると、Claudeは `CLAUDE.md` の指示に従って**読みに行く前に自分で断る**。
> これは①の効果であって、`settings.json` の deny ルールまで届いていない。
> 上のコマンドは**文字を表示するだけの無害な命令**で、Claude自身が断る理由がない。
> それでも止まるなら、止めているのは `settings.json` の `Bash(*Production_Management_v2*)` である、と切り分けられる。
> 表示されるのは「実行に失敗しました/権限が拒否されました」という**赤いエラー**。
> なお deny ルールなので、**許可ダイアログで「許可」を選んでも通らない**のが正しい動作。

- [ ] ①②③すべて通った

**どれか失敗したら**:置き場所(`C:\Users\<名前>\.claude\`)、ファイル名、拡張子を確認し、アプリを再起動。
