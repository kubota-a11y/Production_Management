# Claude 使い始めガイド(山本さん用・最初の2週間)

セットアップが終わったあと、実際にどう使うかのガイド。印刷して手元に置いてもよい。

---

## Claudeに聞いていいこと・貼っていいもの

### 聞いていいこと(どんどん使う)

- 文章の下書き(お客様へのメール、納期回答、見積の説明文)
- 考えの整理(「この注文、何から確認すべき?」)
- HiBoardの使い方(分からない画面の操作)
- Excelやパソコン操作の質問
- 写真作業の手順の相談

### 貼っていいもの・いけないもの

**詳しくは同じフォルダの `AI利用ルール.md`(A4版は `AI利用ルール_社内共通.pdf`)に従う。**要点だけ:

- ○ 案件の内容、お客様の会社名・お名前・連絡先、文章の下書き(会社のTeamアカウントは入力内容が学習に使われないため)
- × **パスワード・ログイン情報**(どんな場面でも)
- × マイナンバー・口座番号・生年月日
- × 従業員の給与・評価の情報、取引先の「社外秘」資料

迷ったら目安はひとつ:**「社外の業者さんにメールで送れるか?」**送れないものは入れない。それでも迷ったら三浦さんか久保田に確認。

## 最初の1週間:壁打ちに慣れる

コピペしてそのまま試せる例。自分の言葉に置き換えてOK。

### 見積・受付の仕事で

```text
チームTシャツ20枚(シルクプリント・2箇所)の見積を作ります。
お客様に確認すべき項目を漏れなくリストにしてください。
```

```text
納期が1週間延びることをお客様に伝えるメールの下書きを作ってください。
理由は生地の入荷遅れです。丁寧すぎず、簡潔に。
```

### EC写真の仕事で

```text
BASEに商品写真をアップロードします。X-T5で撮ったJPEGが10枚あります。
アップロード前にやるべきこと(リサイズ・ファイル名・順番)を手順にしてください。
```

### HiBoardの仕事で

```text
HiBoardで案件の進捗を入力する時、入力漏れが多くて困っています。
毎日の入力チェックリストを作ってください。
```

### コツ

- **1回で完璧を求めない。**出てきた答えに「もっと短く」「この部分を詳しく」と続けて直させる
- **背景を伝えるほど良い答えが出る。**「誰に」「何のために」を最初に書く
- 答えが怪しいと感じたら三浦さんに確認。**Claudeは間違えることがある**

## 2週間目から:定型業務に組み込む

慣れてきたら、毎日の仕事に固定で入れる。

| 業務 | Claudeにやらせること |
|---|---|
| 朝イチ | 今日の案件リストを貼って「優先順に並べて」 |
| 見積作成 | 内容の抜け漏れチェック → freee転記前の確認 |
| メール | 全部下書きさせてから自分で直す |
| EC写真 | アップロード前のチェックリスト消化 |

---

## 困ったとき

| 状況 | 対応 |
|---|---|
| Claudeの使い方が分からない | まずClaude自身に聞く(「〜はどうやるの?」) |
| 答えが合っているか自信がない | 三浦さん |
| ログインできない・エラーが出る | 久保田 |
| 「使用上限」の表示が出た | 時間を置けば戻る。頻発するなら久保田に報告 |

## 上限について

山本さんのシート(Standard)には使用量の上限がある。
5時間ごとの枠と週の枠があり、使い切ると一時的に使えなくなるが、**故障ではない**。
時間が経てば自動で戻る。上限に当たった日をメモして久保田に伝えてもらえれば、プランの調整を検討する。
