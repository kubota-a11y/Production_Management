## 0. Git for Windows を入れる(必須・先にやる)

**Windows版のClaude Codeは、ローカルセッションの実行に Git for Windows を使う。**
入っていないと Codeタブでフォルダを選んだ瞬間に「Gitをインストール」と出て先に進めない。

`git-scm.com` からWindows版をダウンロードして実行する。インストーラーの選択肢は
**下の3つ以外はすべて既定のまま Next** でよい。

| 画面 | 選ぶもの | 理由 |
|---|---|---|
| Choosing the default editor | **Use Notepad**(一番下) | 既定の Vim は閉じ方が分からず固まる。**Notepad++ は別アプリで未インストールなので選ばない** |
| Adjusting your PATH environment | **真ん中(既定)のまま** | 一番上を選ぶと**Claude CodeからGitが見つからず、同じエラーに戻る** |
| initial branch name | Override → `main` | HiBoardのリポジトリに揃える(実害はないが揃える) |

Experimental options には**チェックを入れない**。

> **Gitを入れてもリポジトリには触れない。**Git本体はClaude Codeが動くための部品で、
> HiBoardのソースを触るにはこの先の clone とGitHubのアクセス権が別途必要。

### Codeタブは作業フォルダの選択が必須

Codeタブで質問すると、最初に「ローカルセッション用のフォルダを選択」が出る。
**ホーム(ユーザーフォルダ)を丸ごと選ばない。**専用フォルダを作る。

1. ダイアログ左の **ドキュメント** をクリック
2. 上部の **新しいフォルダー** → `Claude作業` と入力
3. そのフォルダに入って **フォルダーの選択**

以降このフォルダを作業用に使う。

## 3. 動作確認 3点チェック

Claudeアプリの **Codeタブ**で順に打つ。

**② 本番反映の担当を理解しているか**


→ **「本番への反映は久保田が行う」**旨が返れば **OK**
(三浦さんの担当はpushまで、という説明が出れば完璧)

**③ ブロックが効いているか**

デスクトップに `.env` という空ファイルを作り、そのフォルダをCodeタブで開いて:

```text

```

→ **権限エラーでブロックされれば OK**
(「読みません」と答えるだけなら①の効果。**エラー表示が出る**のが③の証拠)

`三浦さん_settings.local.json` を、cloneしたリポジトリ内に
**`.claude/settings.local.json`** という名前で置く。

このファイルはgit管理外なので、リポジトリを更新しても消えない。

リポジトリの `CLAUDE.md` が読めている。
**最後の update.bat は久保田がサーバー用PCで実行する**ことを口頭でも確認する。
