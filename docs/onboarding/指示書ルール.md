「指示書を作って」「加工指示書にして」と頼まれたら、Claude はこの手順とフォーマットで作る。

- 正本の更新は久保田が行う。**修正したい点は §6 の「修正メモ」に書いて残す**(次の改定で反映する)
- 置き場所: 共有ドライブ `HiYOSHi共有/Claude設定/共通/指示書ルール.md`(控え: HiBoardリポジトリ `docs/onboarding/指示書ルール.md`)

最終更新: 2026-09-04(初版)

---

## 1. 指示書の目的

**生産ライン(渡邉さん・パートさん)が、誰にも聞かずに加工へ入れる紙**を作ること。
読むのは作った本人ではない。「これを見た人が、ボディを取り出して、正しい位置に、正しいデータを、正しい枚数だけ加工できるか」だけを基準にする。

---

## 2. 材料(入力)と作り方(手順)

### 材料として渡すもの(あるものだけでよい)

- お客様とのやり取り(LINE・メールの本文を貼る)
- 発注書・注文票・手書きメモ・打ち合わせメモ
- 見積書(freeeの見積番号 Q-xxxxxxx)
- HiBoardの案件情報(案件名・受付番号・数量・サイズ内訳)
- デザインデータのファイル名・保存場所

### 手順(Claudeがやること)

1. 材料を読み、§3 の項目を**分かるところだけ**埋める
2. **分からない項目は推測で埋めない。** `【要確認】` と書いて黄色いマスにし、§3 の「未確定事項」に一覧で集める
3. 数量の検算をする: サイズ内訳の合計 = 品番ごとの数量 = 全体の合計
4. 品番ごとに1ページの原稿(Markdown)と、印刷用(HTML・A4縦)を作る
5. 最後に §5 のチェックリストを通し、通らなかった項目を本人に伝える

### 保存先と名前

- 原稿: `G:\共有ドライブ\HiYOSHi共有\Claude成果物\(自分の名前)\指示書\YYYY-MM-DD_(案件名)_加工指示書_原稿.md`
- 印刷用: 同じフォルダに `YYYY-MM-DD_(案件名)_加工指示書.html`(ダブルクリック → Ctrl+P でそのまま印刷できる形)
- 確定したら PDF にして **HiBoardの案件フォルダ(共有ドライブの案件フォルダ)へ保存**し、HiBoardの納品時チェック「指示書PDFを保存した」に対応させる
- 案件名にお客様名が入るのは業務上必要なので可(社内の共有ドライブに限る)

## 3. フォーマット(A4縦・1品番1ページ)

### 1ページ目(案件全体)

| 項目 | 書き方 |
|---|---|
| 案件名 | HiBoardの案件名と同じにする |
| 受付番号 | HiBoardの番号(L-/W-/T-/P-) |
| 得意先 | 会社名・チーム名・担当者名 |
| 担当(社内) | 三浦 / 山本 |
| 作成日・版 | 例: 2026-09-04 v1(直したら v2、v3 と上げる) |
| 納期 | 年月日(曜日)。「◯日まで」「◯日必着」の区別を書く |
| 納品先・納品方法 | 店舗名・住所の有無・配送/手渡し/引取り |
| 見積番号 | freee の Q-番号(金額は指示書に書かない。金額は見積書に任せる) |
| 全体の数量 | 合計点数と、品番ごとの点数の一覧 |
| 加工方法(全体) | DTF / シルク / ラバー転写 / 刺繍 / マーキング のどれか。混在なら品番ごとに書く |
| データの保存場所 | 共有ドライブのフォルダとファイル名 |
| **未確定事項** | `【要確認】` の一覧。**誰に・何を・いつまでに確認するか**まで書く |

### 2ページ目以降(品番ごとに1ページ)

| 項目 | 書き方 |
|---|---|
| ボディ | メーカー・品番・商品名(例: United Athle 5001-01 5.6oz ハイクオリティTシャツ) |
| 色 | メーカーのカラー名とカラー番号(例: ブラック 002) |
| サイズ内訳 | 表にする: サイズ ／ 枚数。**合計欄を必ず付ける** |
| 加工箇所 | 箇所ごとに1行: 位置(前中央・左胸・背中・右袖 など)/ プリントサイズ(A4・A3・または ヨコ◯cm×タテ◯cm)/ 基準位置(衿下◯cm・中央 など)/ データ名 / 色数・糸色 / 加工方法 |
| 個人名・番号 | 選手名・背番号があるときは、サイズ・番号・名前の一覧表。**枚数と行数が一致すること** |
| 仕上げ | 袋入れ・畳み方・タグ付け・個別包装・名札の有無 |
| 位置図 | 前面・背面の簡単な図に、箇所の番号を振る(HTMLでは枠で代用してよい) |
| 特記 | 注意点(厚手・ナイロン・重ねプリント・持込品・過去のクレーム など) |
| 【要確認】 | この品番で未確定の項目(黄色いマス) |

### 表記の決まり

- サイズ表記は **A4/A3 か cm** に統一(混ぜない)。cm なら ヨコ×タテ の順
- 位置は「着た人から見て」の左右で書き、迷う場合は「左胸(着用者の左)」のように添える
- 色名は**メーカー表記**を使い、自分の言葉(「濃い青」等)に置き換えない
- 数字は**出典を持つ**(どのメッセージ・どの資料から取ったか)。原稿の末尾に「出典メモ」として残す
- 日付は 年/月/日(曜日)

---

## 4. やってはいけないこと

- 推測で埋める(**指示書の間違いは、そのまま加工ミスになる**)
- 金額を書く(見積書と二重管理になり、食い違いのもと)
- 材料に無い加工方法・位置・サイズを「たぶんこう」で決める
- サイズ内訳と合計が合わないまま出す
- 顧客名・連絡先を社外のサービスに貼る(社内の共有ドライブとHiBoardの中だけで扱う)

---

## 5. 提出前チェックリスト(Claudeが最後に自分で確認する)

- [ ] 納期・納品先・納品方法が入っている
- [ ] 品番ごとの数量の合計 = 全体の合計
- [ ] サイズ内訳の合計 = その品番の数量
- [ ] 個人名・番号の一覧の行数 = 枚数
- [ ] すべての加工箇所に「位置・サイズ・データ名・加工方法」が揃っている
- [ ] データのファイル名と保存場所が書いてある
- [ ] 【要確認】が一覧にまとまり、確認先と期限がある
- [ ] 金額を書いていない
- [ ] 1品番1ページで、印刷したときに1ページに収まる

## 6. 修正メモ(精度を上げるための記録)
