# Claude 使い始めガイド(鈴木さん用・デザイン業務向け)

セットアップが終わったあと、実際にどう使うかのガイド。

## Claude に頼んでいいこと

- 指示書と入稿データの**突き合わせチェック**(サイズ・箇所・色数・書体・形式)
- 画像の**一括リサイズ・形式変換・ファイル名の統一**、案件フォルダの整理
- 印刷物の**文字校正**、商品説明文やキャプションの下書き
- 業者(トレス・印刷会社)への**入稿・発注メールの下書き**(送信は自分で)
- 配色・レイアウト・コンセプトの**壁打ち**
- Mac の操作、ターミナル、ファイル形式の質問

Claude が苦手なこと: Illustrator のファイルを直接いじること。.ai の編集は自分で行い、Claude には手順・チェック・書き出し後の確認を任せる。

## 貼っていいもの・いけないもの

要点だけ(詳しくは `AI利用ルール_社内共通.pdf`):

- ○ 案件の内容、お客様の会社名・お名前、指示書、デザインデータの書き出し(PNG/PDF)、文章の下書き
- × **パスワード・ログイン情報**(どんな場面でも)
- × マイナンバー・口座番号・生年月日
- × 取引先の「社外秘」資料

迷ったら「社外の業者さんにメールで送れるか?」。送れないものは入れない。

## 最初の1週間: コピペで試せる例

```text
この指示書(貼り付け)と、書き出したPNGのサイズ・箇所・色数が合っているかチェックしてください。
分からない項目は【要確認】にしてください。
```

```text
~/Claude作業/入稿 にあるJPEG 12枚を、長辺2000pxに縮小してPNGに変換し、
ファイル名を 案件名_01.png のように連番にしてください。元ファイルは残してください。
```

```text
トレスの真船さんへ、昇華ユニフォームの入稿データを送るメールの下書きを作ってください。
添付: 入稿データ.ai と注文書.xlsx。納品希望日は10月末。丁寧すぎず簡潔に。
```

```text
このチラシの文章(貼り付け)の誤字・表記ゆれをチェックして、直した理由も一緒に出してください。
```

### コツ

- **1回で完璧を求めない。**「もっと短く」「ここだけ詳しく」と続けて直させる
- **「誰に」「何のために」を最初に書く**と答えが良くなる
- 数字・書体名・色指定が怪しいと感じたら指示書と山本さんに確認。**Claude は間違えることがある**

## 困ったとき

| 状況 | 対応 |
|---|---|
| 使い方が分からない | まず Claude 自身に聞く |
| 指示書の内容・案件の進め方 | 山本さん |
| ログインできない・エラー | 久保田 |
| 「使用上限」の表示 | 時間を置けば戻る。頻発するなら久保田へ |

## 上限について

鈴木さんのシート(Standard)には使用量の上限がある(5時間ごとの枠と週の枠)。使い切ると一時的に使えなくなるが**故障ではない**。上限に当たった日をメモして久保田に伝えてもらえればプランを見直す。
