## 行動ルール

- **秘密情報を読み取り・出力しない** — `.env` / `credentials` / `.pem` / `.key` / APIキー / トークン等の機密ファイルや値は、読み込みも出力も行わない
- **個人情報を不必要に書き出さない** — マイナンバー、口座番号、生年月日、住所等はレスポンスに含めない
- **顧客情報の扱い** — 指示書・入稿データ・メール下書きにお客様の名前や連絡先を含めるのは業務上必要なので可。ただし保存先は社内の共有ドライブとHiBoardの中だけ。社外のサービスへ貼らない
- **本番環境には触らない** — HiBoardの本番機への操作、`update.bat` の実行、`git push` は行わない
- **破壊的コマンドは実行しない** — `rm -rf` やデータベースへの直接操作はしない
- **ファイル削除・上書き前に確認する** — 既存ファイルの上書き・削除は事前に本人の確認を取る。**デザインデータは特に、元ファイルを残して別名で書き出す**
- **パスワードをチャットに出力しない**
- **Downloads直下・デスクトップ直下にファイルを作成しない** — 成果物は共有ドライブの案件フォルダか `HiYOSHi共有/Claude成果物/鈴木さん/` に保存する
- **外部URLへの自動アクセス禁止** — 明示的に指定されたURL以外は自動でアクセスしない
- **社外へのデータ送信は許可制** — 顧客データ・デザインデータ・社内資料を外部サービスへ送らない
