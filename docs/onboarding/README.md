## 設計の考え方

**3層で権限を分けている。**

1. **`.claude/settings.json`(リポジトリ共有・git管理)** — 全員に効く。誰であっても触ってはいけないもの(`.env`、鍵ファイル、LINE API資料、`rm -rf`)だけを禁止している
2. **`.claude/settings.local.json`(個人ごと・git管理外)** — 人によって変える。山本さんはgit pushを禁止、三浦さんは確認付きで許可
3. **`~/.claude/CLAUDE.md`(個人ごと)** — その人の役割と判断基準

久保田の `~/.claude/CLAUDE.md` は経営情報を含むため**そのまま配らない**。ここにある個人別のものを使う。

## MTG決定事項の配り方(2026-09-02〜)

MTGで決まった全員共通のルールは、各自の CLAUDE.md には書かず **共有ドライブの `Claude設定/共通/チーム共通ルール.md` 1ファイル**にまとめる。
各自の `~/.claude/CLAUDE.md` の最終行 `@G:/共有ドライブ/HiYOSHi共有/Claude設定/共通/チーム共通ルール.md` がこれを起動時に読み込む。

- 更新: 久保田が MTG 後に `/mtg-sync`(久保田Macのスキル)で正本を更新 → Googleドライブが社員PCへ同期 → **社員は Claude Code を開き直すだけ**。git pull も配布も不要
- 控え: このフォルダの `チーム共通ルール.md`(正本と同一内容。履歴を残すためにここにも置く)
- 個人の役割・権限が変わったときだけ、従来どおり個人別 CLAUDE.md を配り直す
- 社員PC側は `共通` フォルダを「オフラインで使用可能」にしておく(ストリーミングだと読めないことがある)
- 日本語入りドライブパスの `@` 読み込みが通らない場合は `mklink /J C:\Users\<名>\.claude\team "G:\共有ドライブ\HiYOSHi共有\Claude設定\共通"` で短いパスを作り、CLAUDE.md の行を `@C:/Users/<名>/.claude/team/チーム共通ルール.md` に変える

## 権限の早見表

| 操作 | 久保田 | 三浦さん | 山本さん |
|---|---|---|---|
| コード修正・ローカル動作確認 | ○ | ○ | ○ |
| `git commit`(ローカル) | ○ | ○ | ○ |
| `git push`(mainへ反映) | ○ | ○(確認付き) | **×** |
| 本番機での `update.bat` | ○ | **×** | **×** |
| `.env`・鍵ファイルの読み取り | × | × | × |

**本番への反映(サーバー用PCでの `update.bat` 実行)は久保田だけが行う。**
三浦さんのPCはサーバー機と切り分けられており、本番機を操作できない。
三浦さんの担当はmainへpushするところまでで、反映は久保田へ連絡して実施する。

山本さんの `git push` を止めているのは、コードの変更を久保田・三浦さんの目を通す形に固定するため。
慣れてきたら `山本さん_settings.local.json` から該当行を消せば解除できる。
