見積書・概算・お客様への価格案内を作るときは、**必ずこのファイルの数字と判定順で組み立てる**。

- 正本の更新は久保田だけが行う(価格改定のたびに反映)。**他の人は手で編集しない**
- 置き場所: 共有ドライブ `HiYOSHi共有/Claude設定/共通/価格ルール.md`(控え: HiBoardリポジトリ `docs/onboarding/価格ルール.md`)

- 反映のタイミング: Claude Code を開いたとき。**価格改定の連絡が来たら一度閉じて開き直す**
- AIは数字を間違えることがある。**見積書を出す前に、本人が表と突き合わせて確認する**

## 0. 見積を作る前の判定(必ずこの順番で)

1. **KRATVSの商品か?** → §7 KRATVSカスタムオーダー表で。パックにもDTF表にも乗せない
2. **八木繊維様(卸)か?** → §8 八木繊維様専用表で
3. **1〜5枚の小口か?** → §1「1枚からパック」の条件に当てはまれば**必ずパック**で受ける(勝手に一般表で積み上げない)
4. **それ以外** → 加工方法の表(§2〜§6)+ボディ(§9)+オプション(§10)で積み上げる

### 税の扱い(ここを間違えると金額が合わない)

| 対象 | 表記 |
|---|---|
| 加工料金表(DTF・シルク・ラバー・マーキング・刺繍)・ボディ単価 | **税抜** |
| freeeの見積書・請求書 | **税抜(外税)** で作る |
| 1枚からパック・KRATVSカスタムオーダー | **税込** でお客様に案内(freeeに入れるときは税抜に戻す) |
| 一般のお客様への表示(サイト・LINE・店頭) | 税込で統一 |

### 社長(久保田)の確認が要るケース

- 距離割引(§12)を適用するかどうか
- シルク **3〜4色で300枚超**(設備占有のため)
- DTF **A3の500枚以上**(資材実測が終わるまで)
- 個別見積の品番(§9)・SLOTHカタログ品番(CJ/ST/DF)の概算(2026-10-04まで)
- ラバー転写で**カス取りが明らかに重いデザイン**
- 価格表に無い加工・仕様、値引きの相談、価格表と実態が合わないと感じたとき
- **納期と価格はその場で即答しない**(パックの定額案内は除く)。見積書として出す

### その他

- **ネーム刺繍(1.5×8cm以内・1枚1箇所): 500円フラット**(10枚未満でも割増なし)

### 案内の流れ
