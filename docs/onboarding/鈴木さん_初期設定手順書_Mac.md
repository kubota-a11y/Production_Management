## Step 1. 招待を受ける(鈴木さん・5分)

1. `suzuki@hiyoshi1954.com` の Gmail で Anthropic からの招待メールを開き、「Accept invitation(招待を承諾)」を押す
2. **「Google で続行」**を選んで `suzuki@hiyoshi1954.com` でログインする(個人の Gmail や Apple ID は使わない)
3. 画面左下に**組織名 Hiyoshi1954** が出ればOK

> **パスワードやログイン操作は鈴木さん本人が行う。**久保田が代わりに打つことはしない。

## Step 2. Claude デスクトップアプリを入れる(5分)

1. `claude.ai/download` から **Mac版**をダウンロードして「アプリケーション」へ入れる
2. 起動して Step 1 と同じアカウントでサインイン
3. 画面上部に **「チャット」「Code」** のタブがあることを確認する

## Step 3. 設定ファイル2点を置く(5分)

共有ドライブ `HiYOSHi共有 > Claude設定 > 鈴木さん` から2ファイルを、自分の Mac の **`~/.claude/`** に置く。

| コピー元 | 置き先 |
|---|---|
| `CLAUDE.md` | `~/.claude/CLAUDE.md` |
| `settings.json` | `~/.claude/settings.json` |

**`~/.claude` フォルダの開き方:** Finder → メニュー「移動」→「フォルダへ移動…」(⇧⌘G)→ `~/.claude` と入力 → 移動。
フォルダが無ければ、ターミナルで次を実行してから同じ手順で開く。

```bash
mkdir -p ~/.claude
```

- 名前を変えずにそのまま置く(`CLAUDE.md.txt` になっていないか確認。Finder の「情報を見る」で拡張子を確認できる)
- 置いたら **Claude アプリを一度終了(⌘Q)して起動し直す**

> この2ファイルは1セット。`CLAUDE.md` は「役割と仕事のルール」、`settings.json` は「機密ファイル・危険な操作のブロック」。両方で防御が成立する。

## Step 4. 共有ドライブのパスを確認する(5分・ここが Mac 固有)

`CLAUDE.md` の最後の2行は、共有ドライブの「共通」フォルダを自動で読み込む設定になっている。
Mac では Google ドライブの場所がアカウント名で決まるので、実際のパスと合っているかを確認する。

ターミナルで:

```bash
ls ~/Library/CloudStorage/
```

- `GoogleDrive-suzuki@hiyoshi1954.com` が表示されればそのままでOK
- 別の名前(例: 個人アドレスでログインしている)なら、**久保田へ連絡**。CLAUDE.md の最終2行のパスを直して配り直す

続けて Finder で `共有ドライブ > HiYOSHi共有 > Claude設定 > 共通` を右クリック →
**「オフラインで使用可能にする」**にチェック(ストリーミングのままだと読めないことがある)。

## Step 5. Code タブの作業フォルダを作る(3分)

Code タブで最初に質問すると「フォルダを選択」と聞かれる。**ホームや書類・デスクトップを丸ごと選ばない。**

```bash
mkdir -p ~/Claude作業
```

を作り、ダイアログでこのフォルダを選ぶ。以後ここを作業用にする。

> iCloud Drive の「デスクトップと書類フォルダ」同期がオンの Mac では、書類の中に作るとクラウド同期に巻き込まれる。
> ホーム直下の `Claude作業` なら同期の外になる。

> Code タブを初めて使うとき、macOS が「コマンドラインデベロッパツールをインストールしますか」と聞くことがある。
> **「インストール」を押して待つ(数分)。**これは Git を使うための部品で、リポジトリを触るわけではない。

## Step 6. 動作確認 3点チェック(必ず実施・5分)

Claude アプリの **Code タブ**で順に打つ。

**① 役割が読まれているか**

```text
私の担当業務は何ですか？
```

→ デザイン制作 / 入稿前チェック / 個人的な引き合いは山本さんへ引き継ぐ、が返れば **OK**

**② 共有ドライブの共通ルールが読めているか**

```text
チーム共通ルールの土日祝の対応を教えて
```

→ 「週明けに連絡します」とだけ返信し、Googleチャットで三浦さんへ集約、が返れば **OK**。
返らなければ Step 4 のパスがずれている。

**③ ブロック設定が効いているか**

```text
ターミナルで echo Production_Management_v2 を実行して
```

→ **赤いエラー(権限が拒否されました)が出て実行されなければ OK**。
「許可」を選んでも通らないのが正しい動作。`.env` で試さないこと(Claude が自分で断ってしまい判定できない)。

- [ ] ①②③すべて通った
