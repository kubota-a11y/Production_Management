🤖 AI利用ルール

社内共通／2026-08-25 案
有限会社HiYOSHi

会社で AI を使うときの共通ルールです。対象は Claude と Gemini の両方。AIは「よく調べてくれる新人」だと思ってください。仕事は速いですが、思い込みで数字を間違えることがあり、判断はしません。最後に確認して決めるのは、いつも人です。

1. アカウント ─ 必ず会社のアカウントで使う

使うもの入力した内容の扱い
Claude
チームプラン(Standard)		入力した内容・AIの回答が、AIモデルの学習に使われません。（法人向けの商用利用規約が適用されるため）
Gemini（会社のWorkspace）会社アカウントで使う限り業務向けの契約が適用されます。個人のGoogleアカウントで開いたGeminiは対象外
個人の無料・Proアカウント
自分のスマホのアプリ		会社の仕事に使わないでください。設定によっては入力内容が学習に使われます

ログイン情報を他人に貸さない。退職・異動のときは席を返却する。

2. 入れてよい情報／入れてはいけない情報

迷ったときの目安：「これを社外の業者さんにメールで送れるか?」 送れないものは、AIにも入れない。
判断情報の種類
入れてよい案件の内容、加工の種類・枚数・納期、お客様の会社名・お名前・電話番号・住所、社内の資料・議事録、HiBoardの画面の見え方、文章の下書き
入れてよい自社の価格・原価・仕入単価（見積書づくりなど、業務に必要な範囲で）
入れないパスワード、APIキー、各種サービスのログイン情報
入れないマイナンバー、口座番号、生年月日
入れない従業員の給与・評価・人事に関する情報
入れない取引先から「社外秘」と示された資料・契約条件
入れないお客様の顔が写っている写真（掲載許可が取れているものを除く）

3. 出す前に、必ず人が確認する ─ AIが作ったものをそのまま外に出さない

出すもの確認する人
SNS投稿（KRATVSのInstagramリールなど）社長　※投稿前に必ず
協賛・取引条件の提示社長　※条件を伝える前に必ず
ホームページに載せる文章・制作実績社長　※お客様の掲載許可も必要
お客様・取引先へ送るメール、見積書山本さん → 三浦さん／三浦さん → 自分で確認
社内資料・議事録のまとめ作った本人が原本と突き合わせる

4. AIは間違える ─ 数字と事実は自分で確かめる

実際に起きた例（2026年8月24日）
  • KRATVSのカタログを確認させたところ、AIは「152ページ」と認識。実際は18ページでした
  • 議事録と録音で「大人ネイビーのインク色」が食い違い。AIは食い違いを見つけられますが、どちらが正しいかを決めるのは人です

金額・数量・納期・サイズ・品番は、AIの出力をそのまま信じない。必ず原本で確認する。

5. HiBoard(生産管理)のこと ─ 誰に聞くか

こと担当・相談先
HiBoardを日々使う（受付・案件登録・進捗入力）三浦さん・山本さん
画面の操作が分からない操作説明資料 → それでも不明なら三浦さん
HiBoardの中身を作る・直す（仕組み・不具合・機能追加）久保田（Claude Codeで開発）
「動きがおかしい」「こう変えたい」久保田へ。自分で直そうとしない。「どの画面で・何をしたら・どうなったか」を書いて渡す

※ Claude Codeでファイルを直接触る場合のみ：開発ルール(CLAUDE.md)を必ず読む／本番反映は久保田の承認後／山本さんは本番反映を行わない。

6. 困ったとき

状況相談先
仕事の進め方の判断山本さん → 三浦さん／三浦さん → 久保田
この情報をAIに入れてよいか判断がつかない入れる前に久保田
誤って入れてはいけない情報を入れてしまったすぐ久保田に報告（隠さない。早いほど手が打てます）
※規約は改定されることがあります。契約時と年1回、最新の規約を確認します（久保田）。　このルールは運用しながら見直します。使ってみて「これは判断に困る」という場面があれば、久保田まで教えてください。
