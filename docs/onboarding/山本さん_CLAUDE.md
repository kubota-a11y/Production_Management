### 山本さんが担当する範囲

三浦さんから振られた案件と、鈴木さん経由で引き継がれた案件を最後まで進行する。

1. お客様とのやり取り(LINE・メール)
2. 見積書の作成
3. 指示書の作成
4. 請求書の発行
5. 三浦さんへ「発注をお願いします」と**指示書と見積書を提出する**(そこから先は三浦さんがボディを発注して生産ラインに乗せる)

**鈴木さん経由の案件** — 鈴木さんに個人的なつながりで注文が入った場合、鈴木さんから「担当は山本さんになります」と引き継がれる。引き継ぎの声掛けを受けたら、そこから先は山本さんが進行する。**引き継ぎの連絡は漏らさないこと。**

### 打ち合わせへの同席

- **サッカー関連の打ち合わせには同席する。** 指示書・見積書に起こしやすくなるのと、三浦さんの接客・話し方を学ぶため。**将来は1人で打ち合わせできるようになるのが目標**

- サッカー関連の打ち合わせでは、全力で愛想よく・笑顔で対応すること

## 行動ルール

- **秘密情報を読み取り・出力しない** — `.env` / `credentials` / `.pem` / `.key` / APIキー / トークン等の機密ファイルや値は、読み込みも出力も行わない
- **個人情報を不必要に書き出さない** — マイナンバー、口座番号、生年月日、住所等はレスポンスに含めない
- **顧客データをログ・出力ファイルに含めない** — 受注情報・会員情報・顧客名等はログや出力ファイルに記録しない
- **本番環境には触らない** — HiBoardの本番機(サーバー用PC)への操作、`update.bat` の実行、`git push` は行わない。**本番への反映は久保田が行う。**必要になったら三浦さん経由で久保田に依頼する
- **破壊的コマンドは実行しない** — `rm -rf` やデータベースへの直接操作はしない
- **ファイル削除・上書き前に確認する** — 既存ファイルの上書き・削除は事前に本人の確認を取る
- **パスワードをチャットに出力しない**
- **Downloads直下・デスクトップ直下にファイルを作成しない** — 所定のフォルダ配下に保存する
- **外部URLへの自動アクセス禁止** — 明示的に指定されたURL以外は自動でアクセスしない
- **社外へのデータ送信は許可制** — 顧客データや社内資料を外部サービスへ送らない
