デザイン業務のスケジュール共有(鈴木さん × HiYOSHi) ｜ 2026年7月27日 初版
この仕組みの目的
デザイン業務の「何を・いつやるか」を、リモートの鈴木さんとHiYOSHiが同じ画面で共有するための仕組みです。 HiYOSHiは仕事(タスク)を渡すだけ、どの日にやるかは鈴木さんが自分で決めます。 鈴木さんが組んだ予定は、社内の週間スケジュールボードにそのまま表示されます。

全体の流れ

HiYOSHi ① 案件を登録する HiBoardで案件登録。デザインの準備項目にチェックを入れるだけ
→
自動 ② タスクが届く 鈴木さんのボードの「日付が未定のタスク」に自動で入る
→
鈴木さん ③ 予定を組む 日付と見込み時間を自分で決める。終わったら完了チェック
→
HiYOSHi ④ 社内で見える 週間スケジュールボードの鈴木さんの行に自動反映

使う画面は3つ

画面誰が使う何をする
マイスケジュールボード
(専用URL)		 鈴木さん 自分の週間予定づくり・完了操作・稼働申告。鈴木さんに関する操作はすべてこの画面で行う
HiBoard(案件登録・週間スケジュールボード) HiYOSHi(久保田・三浦) 案件とデザインタスクの登録、鈴木さんの予定・進み具合の確認
社員用TODOリスト(スプレッドシート) 両方 案件にひも付かない細かい仕事の受け渡し。従来どおり記入・完了はシートで行う

役割分担の原則

  • HiYOSHiは「何を・いつまでに」を渡す — 案件の納期は伝えるが、作業日は指定しない
  • 鈴木さんは「どの日にやるか」を決める — CARVE業務との兼ね合いは鈴木さん自身が調整する
  • 稼働できない日は先に申告する — 稼働変更ボタンで申告すれば、HiYOSHiは納期回答や割り振りを調整できる。申告にペナルティはなし。困るのは無申告の遅れだけ
稼働の目安: 1日6時間 × 週5日(月〜金) = 週30時間。 週によって増減がある場合は、マイスケジュールボードの「⚙ 稼働変更」で日ごとに申告します。

HiYOSHi側の手順(久保田さん・社内)

1. デザインの仕事を渡す = 案件を登録するだけ

案件登録時に、鈴木さんの仕事に当たる「作業の準備項目」にチェックを入れると、その項目が自動で鈴木さんのボードに届きます。追加の操作は一切不要です。

案件の種類登録方法鈴木さんに届く項目
社内デザイン案件
(KRATVS・販促物・自社デザイン)		 新規案件 → 案件種別「社内デザイン」を選択。案件名・納期・準備項目だけの簡単登録 チェックした全部の準備項目
通常案件
(お客様からのオーダー)		 従来どおり登録 チェックのうちデザイン系5項目だけ(下記)

デザイン系5項目(鈴木さん専用の準備項目): 外注用デザインデータ作成 / 販促物用データ作成 / DTFデータ作成 / 作業指示書作成 / 見積書作成

2. 細かい仕事はTODOスプレッドシートで渡す

案件にするほどでもない仕事は、従来どおり社員用TODOリストのTODO_鈴木タブに書きます(朝会の議事録からの自動追記もそのまま)。状態を「進行中」にすると鈴木さんのボードのTODOリストに表示されます(未着手は表示されません)。

3. 進み具合は週間スケジュールボードで見る

HiBoardヘッダー「🗓️ スケジュール」の鈴木さんの行に、本人が組んだ予定が表示されます。

表示意味
紫の縞ブロック【準備】案件由来のデザインタスク(完了すると緑になる)
青緑の縞ブロック【TODO】TODOリストから本人が予定に入れたタスク
🎨 デザイン 📋 デザイン関連業務本人が申告した「その日の仕事の種類」の意向(次項)
「休み」表示・時間の減少本人の稼働申告(終日不可・時間短縮)が反映されたもの

4. 日別バッジの汲み取り方

  • 🎨 デザイン の日 = デザインに専念したい日。指示書・見積書などの依頼や割り込みはなるべく避け、翌日以降に回す
  • 📋 デザイン関連業務 の日 = 指示書・見積書・データ整備などの細かい仕事を受けられる日
社内からは鈴木さんの予定を直接動かさないのが原則です(【TODO】ブロックはそもそも動かせません)。 調整したいときは、朝会・LINEで本人に伝えて本人のボードで動かしてもらいます。

5. デザインが全部終わると

案件の準備項目がすべて完了すると、案件ステータスが自動で「準備完了」に進みます。社内デザイン案件はこれで実質完成、通常案件は次の生産工程(三浦さん側)へ渡ります。

鈴木さん側の手順(マイスケジュールボード)

0. 画面を開く

  • 共有された専用URLをブラウザで開く(PC・スマホどちらでも可)。ブックマーク推奨
  • 画面は上から「今週の予定」→「日付が未定のタスク」→「TODOリスト」の順
  • 「日付が未定のタスク」の中では、CARVE案件は「🔶 CARVE案件」の見出しから下にまとめて表示される
URLは鈴木さん専用です。他の人に共有しないでください(URLを知っていれば誰でも開けてしまうため)。

1. 週の初め(月曜の朝会前後): 今週の予定を組む

  1. 「日付が未定のタスク」「TODOリスト」を確認する
  2. 各タスクの 日付を選ぶ プルダウンで、やる日を決める(日付カードへのドラッグでもOK)
  3. 見込み時間(h)を入れる — 日カードの「◯h / 6h」でその日の詰まり具合が見える。6hを超えると赤字になるので入れすぎのサイン
  4. 稼働できない日・短い日は ⚙ 稼働変更 で申告する(終日不可 / 時間指定 / 通常に戻す)
  5. 各日の 🎨 デザイン / 📋 デザイン関連業務 ボタンで、その日の仕事の種類の意向を表明する(もう一度押すと解除)

2. 日々: 進めながら更新する

  • 終わった案件タスクは「完了」にチェック → 社内に自動で伝わる(取り消しも可)
  • 校正がどこまで進んだかは、カード内の 初校 修正 校了 のバッジを押して切り替える(もう一度押すと未選択に戻る)。案件ごとなので、同じ案件のカードはまとめて同じ状態になる
  • TODOの完了はスプレッドシート側で「完了」にする(ボード側に完了チェックはありません)
  • 予定がずれたら、日付プルダウンで別の日へ動かす。いったん白紙にしたいときは ↩︎ 未定に戻す
  • 週をまたぐ移動は「次週 →」で翌週を表示してから日付を選ぶ

3. 間に合わなそうなとき(いちばん大事)

「間に合わない」と分かった時点で、すぐ動かす+伝える。
① ボード上でタスクを後ろの日へ動かす → ② 朝会かLINEでひとこと伝える。
早く分かれば納期の再調整・お客様への先回り連絡など打てる手があります。申告にペナルティはありません。

よく使う操作まとめ

やりたいこと操作
タスクをある日に入れるタスクの「日付を選ぶ」で曜日を選択(ドラッグ&ドロップでも可)
別の日へ動かす / 未定に戻す日カード上のタスクの「日付を選ぶ」で変更 / 「↩︎ 未定に戻す」
見込み時間を入れるタスクの「h」欄に数字(0.5刻み)

注意点(全員共通)

注意点理由・対処
TODOリストに出るのは「進行中」だけ 未着手まで出すと量が多くなりすぎるため。鈴木さんに予定を組んでほしいTODOは、シートで状態を「進行中」にしてから渡す
同じ名前のTODOは1件として扱われる シートの行に通し番号がないため、タスク名で見分けている。別々の仕事なら「ペルル 請求書作成①」「②」のように名前を変えて書く
日付を決めたTODOの名前をシートで書き換えない 名前で照合しているため、書き換えると日付との紐づけが外れて未定に戻る。名前を直したいときは、直した後にボードで日付を入れ直す
TODOの内容・完了はシートがマスター ボードが覚えているのは「どの日に・何時間」だけ。内容の修正・完了は必ずシート側で行う(ボードへの反映は最大1分)
稼働の時間指定は9:00開始として記録される 例: 「3時間」と申告→社内ボードでは9:00〜12:00と表示される。時間帯まで正確に伝えたいときは朝会・LINEで補足する
デザイナーリンクを無効化している間の案件登録 タスクの自動振り分けが働かない。リンクは常時「有効」のままにしておく(無効化はやめる時だけ)

困ったときは(Q&A)

症状確認すること
登録した案件のタスクが鈴木さんのボードに出ない ①案件の「作業の準備項目」にチェックが入っているか ②通常案件の場合、その項目がデザイン系5項目か(それ以外は社内の担当) ③デザイナーリンクが有効か
シートに書いたTODOがボードに出ない ①状態が「進行中」になっているか ②タブがTODO_鈴木か ③1分待って再読み込みしたか
完了にしたのにTODOがボードに残っている 反映まで最大1分。再読み込み(スマホは引っ張って更新)で消える
社内ボードに鈴木さんの行がない 従業員管理で鈴木さんが「有効」か、基本スケジュール(月〜金6時間)が設定されているか
ページが開けない・「ご利用いただけません」と出る URLが途中で切れていないか、リンクが無効化されていないか(HiBoard「🎨 デザイナーリンク」で確認・再有効化)
