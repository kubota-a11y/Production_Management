今週は見積シミュレーターの作り込みが中心です。大きくは3つ。①金額の表示が「税抜(外税)」に統一されました。②見積書の明細が、手書きで作っていたときと同じ並びになりました。③サイズごとの枚数を入れられるようになりました。
各見出しの右にある社員全従業員は、その項目を読んでいただきたい方の目安です。
見積

金額の表示が「税抜」に統一されました

社員 8/25
  • 見積シミュレーターの画面・転記シート・freeeの見積書がすべて税抜(外税)になりました。消費税は小計に対して最後に1回だけかかります。
  • お客様にお出しする合計金額は今までと変わりません。料金表の単価がすべて10円単位のため、計算の順番を変えても総額が同じになることを確認済みです。
  • 送料・袋入れ・ボディ単価の手入力も税抜で入れてください。画面のラベルもすべて「税抜」に直してあります。
  • ホームページの料金シミュレーター(お客様向け)は税込表示のままです。一般のお客様への価格表示は総額で出す決まりのため、意図的に分けています。
見積

見積書の明細が、手書きのときと同じ形になりました

社員 8/25
ボディ(枚数)→加工1箇所ごと→製版代→袋入れ→送料
  • これまで1行にまとまっていた見積書が、上の並びで1行ずつに分かれます。→ お客様が何にいくら払うのかが読み取れる見積書になりました。
  • 明細に「品名」の欄が増え、「摘要」と分かれました。品名に商品名、摘要に色・サイズ・加工の内容が入ります。
  • 割引を使ったときは、行ごとに「通常価格◯円 → 特別割引◯%OFF」と摘要に出ます。値引きしたことが見積書の上でも分かる形です。
  • ミニマム手数料がかかる場合は摘要に「※ミニマム手数料込み」と入ります。
  • これまで手作業で作っていた見積書を、シミュレーターで1円まで同じに再現できることを確認済みです。

WEEKLY UPDATE

サイズ内訳・製版代・品番の追加

Vol.7 ─ 対象期間:8月25日〜8月31日
見積

サイズごとの枚数を入れられます

社員 8/25
  • 内訳の入力が「価格帯を選ぶ」から「サイズごとに枚数を入れる」形に変わりました。→ S:2・M:3・L:5・XL:5・2XL:5 のように入れると、行の合計枚数は自動で出ます。
  • 価格帯はサイズから自動で決まります。子供サイズ(110〜150)・アルファベット・日本式・レディースの4体系に対応しています。
  • 単価の違うサイズが混ざると、見積書の明細も自動で分かれます。→ 上の例なら「S〜XLで15枚」と「2XLで5枚」の2行になり、それぞれの摘要にサイズ内訳が入ります。
  • 持込ボディやリストに無い品番は、これまでどおりサイズを手打ち+枚数で入力してください。
見積

追加注文で「製版代を含めない」を選べます

社員 8/25
  • 前回の版や作成済みの刺繍データが使える追加注文のとき、加工の行にある「製版代を含めない」にチェックを入れると初期費用が外れます。刺繍・帽子刺繍のときは「パンチング代を含めない」の表記になります。
  • チェックが出るのは初期費用がありうる加工だけ(シルク・刺繍・帽子刺繍)です。DTF・ラバー転写・マーキングには出ません。
  • 見積書の摘要に「※前回の版を使用(製版代なし)」と自動で入ります。→ なぜ初期費用が無いのかがお客様に伝わります。
  • 10枚未満のシルクプリントも金額が出せるようになりました。原則お受けしない加工ですが、ご希望のお客様には10枚時の単価×ミニマム5割増で特別対応する運用に合わせています。→ 「自動(安い方)」では選ばれません。シルクを指定したときだけ出ます。

受注候補・制作実績・AI利用ルール

Vol.7 ─ 対象期間:8月25日〜8月31日
受注

受注候補に「持ち込みボディが届いたか」が出ます

全従業員 8/27
  • お取引先からはオーダーフォームが先に届き、持ち込みのボディが未着のまま受注候補に残ることがあります。「登録が遅れている」のか「ボディ待ちで止めている」のかを、カード上で区別できるようにしました。
  • バッジは3つ。📦持ち込みボディ未着 / ✅持ち込み済・登録待ち / ⏳登録待ち。取引先フォームからの受付は「未着」で始まります。
  • ボディが届いたら「✓届いた」を押してください。戻すときは「📦未着にする」です。未着のカードには持ち込み予定日、すべてのカードに受付からの経過日数が出ます。
  • 絞り込みに「📦持ち込み未着」を追加しました。→ ボディ待ちの案件だけをまとめて確認できます。
その他

制作実績の取り下げ / AI利用ルールを配りました

全従業員 8/25〜8/27
  • ホームページに載せた制作実績を、あとから取り下げられるようになりました。→ 実績の本文とその実績だけで使っている写真がまとめて消えます。ガイドの「登録すると取り消せません」の記載も直しました。

  • お客様の氏名・電話番号・住所、原価や仕入単価は「入れてよい」情報です(会社のTeamプランは入力内容が学習に使われないため)。

皆さんへのお願い(今週からの動き方)

  • 見積シミュレーターに入れる金額はすべて税抜です。送料・袋入れ・ボディ単価の手入力にご注意ください。

  • AIを使うときは必ず会社のアカウントで。個人アカウントでの業務利用は禁止です。ルールはA4 1枚にまとめてありますので、一度目を通してください。
