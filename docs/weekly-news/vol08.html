加工料金を改定しました(9/1・9/2)

社員 9/1〜9/2
  • DTFプリント(9/1) … 1〜5枚・6〜9枚の小口の段と、200枚〜・300枚〜・500枚〜の大口の段を新しく作りました。よく出る10〜99枚は値下げしています。
  • シルクスクリーン(9/2) … 100枚〜・200枚〜・300枚〜・500枚〜の大口の段を新設しました。10〜99枚と製版代は今までどおりです。
  • ラバー転写(9/2) … 1〜4枚だけ値上げ(赤字になっていたため)、5〜9枚と10枚〜は値下げしました。カス取りの手間が枚数どおりに増える加工のため、200枚以上の大口の段はあえて作っていません。
  • 刺繍(9/2) … 段の分け方を「1〜2箇所 / 3〜9箇所 / 10〜49箇所 / 50箇所〜」に整理しました。お客様への請求額はこれまでと変わりません(ミニマム手数料を単価の中に組み込んだためです)。マーキングは単価そのままです。
  • 改定前に出した見積書の単価はそのまま使い回さないでください。同じ内容でも金額が変わっています。金額の正しさに迷ったら、シミュレーターで出し直すか久保田までご確認ください。
見積

ミニマム手数料が残るのは「シルク」だけになりました

社員 9/1〜9/2
シルク:10枚未満は5割増／DTF・ラバー転写・マーキング・刺繍:割増なし
  • これまで同じ品番で10枚未満のときに一律で5割増していたミニマム手数料が、シルクプリント以外では掛からなくなりました。少ない枚数のご相談に、そのままの単価でお答えできます。
  • 例:DTFのA4を6枚のとき、加工代が2,510円 → 1,670円(税抜・1枚あたり)になりました。DTFのネームプリントも560円 → 370円です。
  • シルクの10枚未満だけは今までどおり5割増です。見積書の摘要に出る「※ミニマム手数料込み」も、実際に掛かった行にだけ出るよう直しました。
  • DTFに付く割増は特急(1週間納期)・一重ブルゾン・持ち込み品の3つだけです。
  • 1〜5枚のご相談は、条件が合えば「1枚からパック」(税込・コミコミ)でその場でお答えできます。判断に迷うときは久保田・三浦さんへ。

見積書の見た目・工場のテレビ表示

Vol.8 ─ 対象期間:9月1日〜9月7日
見積

見積書の単価・明細・件名が読みやすくなりました

社員 9/1
  • 見積書に出る単価がすべて10円単位に切り上げられます。割増やボディ単価、割引の後も同じです。→ 「1,673円」のような半端な単価がお客様の見積書に出なくなりました。
  • 明細の「品名」の欄は使わない形に戻し、品番と商品名は摘要のいちばん頭に入れるようにしました。→ 摘要だけを見れば1行の内容がすべて読めます。(Vol.7でご案内した「品名の欄が増えます」は、この形に差し替えです)
  • 見積書の件名が「品名 加工名 数量」で自動作成されるようになりました。お客様のお名前は件名に入りません(取引先の欄で分かるためです)。
  • KRATVSカスタムオーダーにドライ長袖Tシャツが加わりました。S〜XL 税込3,080円 / XXL 税込3,300円で、サイズはこの2つの帯だけです。
現場

工場のテレビに「今日の予定」を映せます

全従業員 9/4〜9/5
  • ヘッダーの「⚙ 管理」→「📺 工場モニター表示」で、今日の予定だけを大きな文字で映す画面が開きます。週間スケジュールボードをそのまま映すと3m先から読めなかったため、テレビ用に作った専用の画面です。
  • 1人1行で、左から「名前」「今日の予定時間 / 勤務時間」「今日やる作業」の順に出ます。🕗空きあり / 🔥入りきらない / 休みの意味はボードと同じで、入りきらない人の行は赤くなります。
  • 作業の札の「準備」は製版・データ作成などの段取り、「提案中」はまだ確定していない予定、✓と取り消し線は終わった作業です。いちばん下の行は明日の予定(土日祝で全員休みの日は、次に誰かが出勤する日)です。
  • この画面では何も変更できません。直したいときは週間スケジュールボードで直してください。テレビ側は1分以内に自動で追いつきます。
  • iPadで映すときは、Safariの共有ボタン →「ホーム画面に追加」で開くとアドレスバーが消えて全画面になります。

マイスケジュール・Claudeの価格ルール

Vol.8 ─ 対象期間:9月1日〜9月7日
スケジュール

マイスケのTODOカードに作業段階の札が付きました

全従業員 9/5
  • 案件のカードには初校・修正・校了の札がありましたが、TODOリストから来たカードには「未着手/進行中」しか無く、いま何をしている段階かが分かりませんでした。→ 「制作 / 修正 / 入稿」の3つのボタンを足しました。
  • 押すだけで切り替わります。もう一度押せば選択が外れます。→ 週間スケジュールボードにも「【TODO・入稿】…」のように段階つきで出ます。他の人からも進み具合が見えるようになりました。
  • この札はTODOシートには書き戻しません。シート側の「未着手/進行中/完了」は今までどおりシートで動かしてください。
  • 案件のカードに付く校正の札(初校・修正・校了)は桃色、TODOの札は緑青色で、色で見分けられます。
その他

Claudeが価格表と指示書のルールを覚えました

社員 9/4
  • 三浦さん・山本さんのClaudeが、起動したときに「価格ルール」と「指示書ルール」を自動で読み込むようになりました。→ 見積の概算や指示書の下書きを、全員が同じ数字・同じ形で作れます。
  • 価格ルールは9/1〜9/3の改定をすべて反映済みです。1枚からパック・DTF・シルク・ラバー転写・マーキング・刺繍・KRATVS・八木繊維様まで1本にまとまっています。
  • 価格が改定されたら、Claude Codeを一度閉じて開き直してください。開いたときにしか新しいルールを読み込みません。
  • AIは数字を間違えることがあります。見積書としてお出しする前に、必ずご自身で料金表と突き合わせてください。納期と価格はその場で即答しないのも今までどおりです(1枚からパックの定額のご案内だけは例外)。

皆さんへのお願い(今週からの動き方)

  • 改定前に作った見積書の単価を使い回さないでください。DTF・シルク・ラバー転写・刺繍は9/1〜9/2で金額が変わっています。見積はシミュレーターで出し直しをお願いします。
  • 10枚未満のご相談にもう5割増は付きません(シルクを除く)。少ない枚数のお問い合わせも、その場で身構えずにお受けしてください。
  • 工場のテレビの内容がおかしいときは、テレビではなく週間スケジュールボードを直してください。1分以内にテレビ側が追いつきます。
  • マイスケのTODOカードは、いまの段階に合わせて「制作 / 修正 / 入稿」を押してください。→ 週間ボードにもそのまま出て、進み具合が全員に伝わります。
  • Claudeで見積の概算を出したら、お出しする前に必ず料金表と突き合わせてください。価格改定の連絡が来たら、一度閉じて開き直しをお願いします。
