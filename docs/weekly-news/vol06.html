今回は変更が多い回です。大きくは3つ。①8/18のミーティングで決めた案件登録のルールが画面に入りました。②見積りをHiBoardで作り、そのままfreeeで見積書を発行できるようになりました。③自分の予定表(マイスケジュール)が大きく使いやすくなりました。
各見出しの右にある社員全従業員は、その項目を読んでいただきたい方の目安です。
受注

案件の登録が「決まっていなくても進める」形になりました

全従業員 8/18
  • 受付の時点で決まっていない項目のせいで登録が止まらないよう、必須をぐっと減らしました。加工内容・プリント箇所は空のままでも登録できます。
  • 案件一覧に「アイテム名」の列が増えました。→ 案件名には正式名称(例:◯◯少年団記念品)、アイテム名には作る物そのもの(Tシャツ、パーカー等)を入れてください。
  • 納期が2つに分かれました。「アイテムの納品納期」(任意)と「デザインの入稿納期」です。入稿納期はデザインが絡む案件だけ必須です。
  • 作業予定時間も「制作予定時間」と「デザイン予定時間」に分かれ、どちらも任意になりました。未定のままスケジュールに置いておき、ボードで入れた時間がそのまま案件に反映されます。
  • 「必要スキル」と「担当者」の入力欄は無くなりました。→ 加工種別を選べば必要スキルは自動で入り、担当者のおすすめもこれまでどおり出ます。入力の手間だけが減ったとお考えください。
  • 連絡経路の選択肢に「Googleチャット」「社長」を追加しました。
お金

入金と支払方法を、案件一覧のその場で記録できます

全従業員 8/18
  • 現金の受け渡しを電話で確認し合っていた状態を解消しました。案件一覧の「決済」列から、その場で記録できます。
  • 記録は2つの軸です。入金の状態=未入金 / 現金預かり(預かった人の名前つき)/ 入金済み。支払方法=現金 / 振込 / クレジットカード(未選択でも可)。
  • 分けているのは「振込だが、まだ入金が確認できていない」という状態をそのまま表せるようにするためです。一覧のバッジには「入金済み｜振込」のように両方が並びます。
  • 支払方法が振込・クレジットカードのときは「現金預かり」を選べません(現金の受け渡しが起こらないため)。
  • 画面や通知の担当表記を「山本さん」から「三浦さん又は山本さん」に統一しました。

WEEKLY UPDATE

見積りが HiBoard で完結します

Vol.6 ─ 対象期間:8月18日〜8月24日
見積

社内用「見積シミュレーター」ができました

社員 8/20〜8/21
受注候補を確認→案件を登録→見積シミュレーター→freeeで見積書を発行
  • HiBoardに見積シミュレーターが入りました。加工料金表がまるごと入っているので、料金表を紙でめくらずに金額が出せます(シルク・DTF・ラバー転写・マーキング・刺繍・帽子刺繍、特急や持込などの割増も含みます)。ボディは253品番、ホームページの料金シミュレーターと同じデータです。
  • お取引先に合わせて3つのモードがあります。通常 / KRATVSカスタムオーダー(セット割を自動判定)/ 八木繊維様(卸)(卸専用の価格表で計算)。
  • サイズ・色ごとの内訳を入れられます。→ サイズで単価が変わる品番も正しい金額になり、見積書の明細もサイズ・色ごとに分かれます。
  • 1つの案件に複数のボディを入れられます。「Tシャツ30枚+パーカー6枚、刺繍はパーカーだけ」といった組み合わせもそのまま計算できます。
  • 割引を使うときは、社長承認のチェックと承認者名を入れないと先へ進めません。値付けの歯止めを画面で担保しています。
  • 案件詳細の「概算の履歴」から開けば、顧客名・品名・枚数・プリント箇所が入った状態で始まります。出した概算はすべて履歴として案件に残ります。単体で開いたときも、あとから案件を検索して紐づけられます。
  • あわせて料金表全体を点検し、抜けていたオプション(色変え手数料・ネーム刺繍・袋入れ 等)を追加、確認シートの取り違えで高くなっていた品番1件をカタログどおりの金額に修正しました。
見積

ボタン1つで freee の見積書ができます

社員 8/21
  • これまで転記シートを見ながらfreeeへ手入力していた作業が、HiBoardのボタン1つで終わります。→ 税区分(内税)の切り替え・宛名の記号・金額の打ち直しが要りません。
  • 見積書の件名は自動で作られます(顧客名・品名・加工名・数量)。書き換えれば手書きが優先され、ボタンで自動に戻せます。同じ文字列がfreeeの社内メモにも入ります。
  • 発行した見積書のURLは案件に自動でひもづきます。顧客台帳・納品履歴からもそのまま開けます。
  • Claude Codeが入っていないパソコンからでも使えます。これまでの「転記シート」方式も残してありますので、当面はどちらでも構いません。

WEEKLY UPDATE

自分の予定表・今週のお願い

Vol.6 ─ 対象期間:8月18日〜8月24日
スケジュール

マイスケジュールが見やすくなりました

全従業員 8/19〜8/21
  • パソコンでは左に今週の予定、右にタスク一覧の2列になりました。→ 下までスクロールしても両方が見えます。スマホ・タブレットはこれまでどおり縦並びです。
  • 右側の「日付が未定のタスク」「CARVE案件」「TODOリスト」は開け閉めできます。閉じていても見出しに件数が出ます。開け閉めの状態はその端末で覚えます。
  • 日付の選択欄に残り時間が出ます(例:木 8/20(残り5.5h / 8h)、多すぎる日は「2.5h超過 / 8h」)。→ 空いている日がひと目で分かります。
  • 1日に複数の稼働時間帯を申告できるようになりました。通院などで中抜けする日は「9:00〜12:00 と 14:00〜17:00」のように分けて入れ、ひとことメモで事情を添えられます。
現場作業

タスク1枚ごとに「今どうなっているか」を書けます

全従業員 8/18〜8/20
  • 作業カードに状態のバッジが付けられます。作業中 / お客様確認中 / 社内確認待ちの3つ。→ 止まっている相手が分かるので、声をかける先が決まります。完了にすると自動で外れます。
  • カードにひとことメモを残せます(「8/18 ◯◯様に連絡済み」など)。完了後も消えません。
  • 自分の担当ではない作業が載っていたら、「🙅 自分の担当ではない」ボタンで自分のボードから下ろせます。→ 案件から作業が消えるわけではなく、担当未定として社内のスケジュールボードに残り、三浦さんが決め直します。※「初校提出」「入稿完了」は案件を先へ進める操作なので外せません。
  • 予定日を先へ動かすと持ち越しとして記録されます。動かすときに理由とひとことメモを伺うウィンドウが出て、カードには「⏩ ◯回持ち越し」が付きます。→ 責任追及ではなく、1日の仕事量が適正だったかを見直すための記録です。
  • 「見積書作成」「作業指示書作成」は鈴木さんのボードから外れました。→ 三浦さん・山本さんの作業として扱います。

皆さんへのお願い(今週からの動き方)

  • 案件登録では「アイテム名」に作る物を入れてください。決まっていない項目は空のままで構いません。分かった時点で足していきましょう。
  • 現金をお預かりしたら、その場で案件一覧の「決済」列に記録してください。電話での確認は不要になります。
  • お見積りは見積シミュレーターで出してください。割引を使う場合は必ず社長の承認を取り、承認者名を入れてください。
  • 自分の担当ではないタスクが載っていたら、「🙅 自分の担当ではない」で下ろしてください。放置せず、その場で解消をお願いします。
  • タスクを翌日以降へ動かすときは、理由とひとことメモを一言お願いします。仕事量の見直しに使わせていただきます。
  • 中抜けのある日は、稼働時間を分けて申告してください。予定の組み方が正確になります。
