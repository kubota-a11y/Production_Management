指示書PDF・工場のテレビ

Vol.9 ─ 対象期間:9月8日〜9月14日
納品

指示書PDFは「受信箱へ送るだけ」になりました

全従業員 9/11
GoodNotesでPDFに書き出す→共有ドライブ「DESIGN / _指示書受信箱」へ送る→HiBoardが案件フォルダへ自動で移す
  • これまでは「PDFを案件フォルダに手で入れてから納品済みにする」順番だったため、フォルダを探す手間で納品の登録が後回しになっていました。→ 置き場所を探す作業をHiBoard側に寄せました。
  • iPadのGoodNotesから共有 → Googleドライブ → HiYOSHi共有 / DESIGN / _指示書受信箱へ書き出すだけです。HiBoardが5分ごとにファイル名を見て、その案件のフォルダへ自動で移します(案件フォルダが無い案件は「DESIGN / 客先名 / 年月_案件名」を自動で作ります)。
  • ノート名(=PDFのファイル名)にHiBoardの案件名を入れておくのがコツです。受付番号「W-12」や案件番号「#123」でも見つけます。どの案件か分からないPDFは受信箱に残ります(間違った案件に入れないためです)。
  • 納品モーダルの「指示書PDF」欄は4つの状態になりました。✅ 案件フォルダにある / 📥 受信箱から選ぶ(★付きが最初から選ばれています) / 💻 このパソコンのPDFを選ぶ / ⏳ 後で保存する。旧「保存した」のチェックは廃止です。
  • PDFが無くても納品済みにして構いません。「後で保存する」で納品した案件は「📦 納品履歴」→「📎 指示書PDF未保存だけ」で絞り込めて、行の「📎 指示書PDF」ボタンから後入れできます。受信箱か案件フォルダにPDFが入れば5分以内に「未保存」が消えます(すぐ消したいときは「📥 受信箱を今すぐ振り分け」)。
  • 書き出した直後の1分間は、共有ドライブの同期待ちのため動かしません。詳しい手順は使い方ガイド(/manual)の第5章とQ&Aにも載せました。
