社内システムお知らせ

今回の大きな変更は3つです。①デザインの仕事を最初から最後まで追える「デザイン進行ボード」ができました。②ご注文の受け口が1本にまとまり、三浦さん・山本さんが行き先を決めてから進める流れになりました。③画面の言葉と並びを見直し、探しものが減りました。
各見出しの右にある社員全従業員は、その項目を読んでいただきたい方の目安です。
デザイン

「デザイン進行ボード」ができました

全従業員 8/4〜8/9
①ブリーフ・ラフ→②制作→③確認→④入稿・製造→⑤請求→⑥検品→⑦納品
  • デザインの案件が今どの段階にあるか、次は誰の番かが、この7段階のボードで一目で分かるようになりました。カードをつかんで隣の段階へ動かすだけで進みます。前にも後ろにも動かせるので、やり直しも同じ操作です。
  • 「確認」は4ステップに分かれました。①お客様へ確認連絡 → ②お客様の返事待ち → ③位置・大きさの調整 → ④最終確認の返事待ち。社内が動く番(①③)だけが「今日やること」に出ます。返事待ちのまま7日過ぎたものは、催促として自動で戻ってきます。
  • 案件を登録するときは、先頭の「案件の型」カードを1つ選ぶだけになりました。よくある4通りから選べば、細かい設定は自動で入ります。当てはまらないときだけ「詳細設定」を開いてください。
  • 紙もの(ポスター等)のように入稿で終わる案件にも対応しました。この型では「初校の納期」と「入稿の納期」を別々に入れられます。CARVE の案件は紫の枠と🔶バッジで目立つようにし、進み具合も4段階(ラフアップ→写真入れアップ→修正アップ→入稿)で分かります。
  • 一覧から「🗂 全般へ」を押せば、その案件をボードに載せられます。要らなくなったらカード右上の「✕」で外せます(案件そのものは消えません)。
  • 表記を「初稿」から「初校」に統一しました。画面・通知・手順書のすべてで同じ言葉になっています。
デザイン

バトンタッチの連絡と、修正のやり取り

社員 8/4〜8/7
  • 担当が交代したことは、システムが自動で Google Chat に流します。「ステータス変えたのでよろしく」「終わったのでよろしく」という手動の報告はもう要りません。同じ段階の中の細かい操作では通知は飛びません。
  • デザインの修正は「✏️ 修正で鈴木さんへ戻す」ボタン1つで回せるようになりました。押すと段階が「制作」に戻り、鈴木さんの作業予定に再び出て、通知も自動で飛びます。修正指示のメモも一緒に送れます。
  • カードには「🔁 修正◯回目」のバッジが付きます。→ 何回やり取りしているかが数字で見えます。
  • 鈴木さんの作業予定には校正の状態バッジ(初校/修正/校了)が付きました。本人が押して切り替えます。また、CARVE の案件はまとめて下に表示されるようになり、通常案件と混ざらなくなりました。

Vol.4 ─ 対象期間:8月4日〜8月10日
受注

ご注文の受け口が1本になりました

全従業員 8/5
  • メールと電話で受けたご注文も、受注候補の画面に入れられるようになりました。メールは本文をそのまま貼り付けるだけ、電話はお客様名とご依頼内容の2つだけで登録できます(数量や納期は聞いたままの言葉で構いません)。→ 通話中でも書き切れます。
  • これでLINE・Web注文・チーム追加・取引先の加工依頼・メール・電話の6つがすべて同じ場所に集まります。頭の記号で見分けてください。W-=Web注文 / T-=チーム追加 / P-=取引先 / M-=メール貼り付け / D-=電話メモ(LINEは記号なし)。
  • 受注候補に「振り分け」が付きました。カードの「🏭 生産 / 🎨 デザイン / 🤝 要相談」の3ボタンで行き先を決めます。これを決めるのは三浦さんと山本さんです。誰がいつ振り分けたかが記録に残ります。
  • まだ振り分けていないものは左端がオレンジになり、一覧の先頭に出ます。タブのバッジの数字も「未振り分けの件数」に変わりました。→ この数字が0になるまで片付けるのが日々の目安です。
  • 🎨デザインで振り分けたものは、案件登録するとそのままデザイン進行ボードの①ブリーフ・ラフに載ります。※「➕新規案件」からの直接登録は振り分けを通りませんのでご注意ください。

Vol.4 ─ 対象期間:8月4日〜8月10日
現場作業

一覧とスケジュールが探しやすくなりました

全従業員 8/8〜8/9
  • 案件名をクリックすると、その場で案件詳細が開きます。これまで納品履歴や顧客台帳からしか開けませんでした。
  • 一覧に検索ボックスが付きました。案件名・お客様名・アイテム名で絞り込めて、件数も出ます。
  • 操作のボタンを「編集」と「⋯ その他」の2つにまとめました。その他を押すと、1つずつ説明付きで並びます。
  • スケジュールの言葉を実態に合わせました。「今週の割り当てを提案」(作られるのは確定ではなく提案です)/「計画不足」→「空きあり」(まだ空き時間があるという意味)/「過負荷」→「入りきらない」。破線のわく=提案中、ふちなし=確定という凡例も常に出ています。
  • 取り消せない操作には、必ず確認が出るようにしました(案件名と残り件数が出ます)。押す前に一度ご確認ください。
  • 画面の名前を統一しました。「デザイン案件全般」→「デザイン進行ボード」、「デザインの予定」→「◯◯さんの作業予定」。また、案件が1件も無い段階は細く畳まれ、iPadでも提案の件数バッジが見えるようになりました。
