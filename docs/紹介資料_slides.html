社内向け ― 生産管理システム「HiBoard」

案件の受付から納品までを、1枚のボードで見えるようにする。

CHAPTER 01  /  社内向け

① 案件管理 今どこまで進んでいるかが、一目でわかる

1ステータスで進行を見える化

  • 受注前 → 確定 → 準備 → 進行中 → 検品 → 納品待ち → 完了
  • 一覧表示とカンバン表示を切り替えて確認
  • 受付日・納期・加工種別・数量・担当者を一元管理

2案件ごとの「準備項目」チェック

  • デザインデータ作成・作業指示書・見積書などをチェックリスト化
  • 全社共通のマスタで管理するので、人によるバラつきが出ない
  • 全部終われば自動で次のステータスへ

3リピート注文は「↻ 再注文」ワンクリック

納品履歴から過去の案件を検索して、ボタンひとつで品目・プリント位置ごと複製。「去年と同じで」という依頼の入力の手間がほぼゼロになりました。

CHAPTER 01  /  社内向け

② 週間スケジュールボード 「誰が・いつ・何を」をドラッグで決める

1マス目に置くだけの予定組み

  • 従業員 × 日付のマス目へ、作業をドラッグ&ドロップで割り当て
  • 案件の見込み時間から1日の負荷を自動集計 ― 入れすぎが色でわかる

2現場の事情もそのまま反映

  • 祝日・人ごとの勤務パターンに自動対応
  • 「この日は終日不可」「午後だけ」などの臨時の稼働変更も登録可

3割り当て漏れを拾う「提案確認パネル」

担当者が決まっていない案件・未着手の案件を自動で拾い上げて表示。「気づいたら誰も手をつけていなかった」を防ぎます。

CHAPTER 01  /  社内向け

③ 受注候補ボックス すべての注文が合流する、たった1つの場所

14つの入り口が1つの一覧に

  • 受付番号を見れば経路がわかる
    W- Web注文   T- チーム注文   P- 取引先依頼   LINE

2新しい注文は社員のTODOへ自動追記

  • 注文が届くと、社員が普段使っているTODOリストへ自動でタスクが追加される
  • 「システムを見に行かないと気づかない」状態をなくすための仕掛け

BEFORE

  • LINE・メール・電話メモを各自が見に行く
  • 誰が対応中か口頭で確認
▶

AFTER

  • 入り口が増えても、見る場所は1つだけ
  • 着信と同時にTODOへ自動で積まれる

CHAPTER 02  /  お客様向け

Web注文フォーム 「まだ決まっていない人」も相談できる3つのモード

1かんたん相談

連絡先と希望の時間帯、ひとこと書くだけ。詳細が決まっていなくても送れるように、あえて入力を最小限に。あとは弊社から電話でヒアリングします。

2見積・イメージ依頼

だいたいの内容と枚数から、見積とデザインイメージをご提案。判断材料がほしい段階の窓口です。

3正式発注

内容が固まっているお客様向け。必要事項をまとめて送信いただけます。

受付番号 + 控えメール

送信後すぐに受付番号を表示し、控えメールを自動送信します。

書きかけを自動保存

入力途中でブラウザを閉じても、24時間は内容が残ります。

スマホ写真もそのまま

iPhoneのHEIC形式を含め、参考画像を添付できます。

CHAPTER 02  /  お客様向け

ご注文の流れガイド ＆ 進捗確認ページ

1ご注文の流れガイド

  • 注文から納品までのステップを、順を追って説明するページ
  • 落ち着いた読み物調のデザインで、はじめてのお客様の不安を減らす
  • 同じ内容をQRコード付きA4チラシ(PDF)にして店頭・同梱でも配布

2注文の進捗確認ページ

  • 受付番号 + 電話番号の下4桁だけで、自分の注文の状況を確認できる
  • 会員登録・パスワード不要。お客様に覚えてもらうものを作らない
  • 表示は4段階にシンプル化 ― 受付済み / 製作中 / 検品・出荷準備中 / 納品済み
ねらい: 「今どうなってますか?」の電話を減らすこと。お客様は待たされず、こちらは手を止めずに済みます。 なお、他人の注文を覗けないよう、照会回数の制限などの安全対策も入れています。

CHAPTER 03  /  クラブチーム向け

チーム追加注文フォーム 「またお願いします」を、やり取りなしで受ける

1チームごとの専用URLを発行

  • 提携チームごとにURLを1本発行してお渡しするだけ
  • チームの担当者は、そのURLを開けばすぐ注文できる
  • 発行・編集・停止・再開はすべて管理画面からワンクリック

2名簿をそのまま入力できる形に

  • 名前 × 背番号 × サイズ × 枚数を行で追加していく入力形式
  • 選べるサイズ(110〜160 / S〜XXL)はチーム・商品ごとに設定可
  • 参考単価・参考合計を自動表示(正式なお見積は後日ご案内)

BEFORE

  • LINEで枚数とサイズを何度も聞き直す
  • 名簿の写真を見ながら手で転記
▶

AFTER

  • チーム側で入力 → そのまま受注候補に着地
  • 聞き漏れ・転記ミスがなくなる

CHAPTER 03  /  取引先(BtoB)向け

取引先ポータル ＆ 加工依頼フォーム

1納期確認ポータル(閲覧専用)

  • 取引先が自社の案件だけの進行状況・納品予定日をいつでも閲覧
  • 案件との紐付けは自動判定。こちらの登録作業は不要
  • ねらいはずばり「上がりはいつ?」の電話をなくすこと

2持ち込み加工依頼フォーム

  • 同じURLから加工の依頼そのものをWebで送信できる
  • 持ち込み予定日・指図書番号・品物ごとの加工内容(方法 × 箇所 × 内容 × 色)・画像添付に対応
  • 加工方法はプルダウン選択(シルク / DTF / ラバー / 刺繍 / 帽子刺繍 ほか)
この先に見ているもの: 現在は当日持ち込み+紙の指図書が中心。ゆくゆくは案件の入力そのものを取引先側で完結していただき、受発注全体をDXしたいと考えています。納期確認ポータルは、その第一歩です。

CHAPTER 03  /  リモートスタッフ向け

デザイナー用マイスケジュールボード 離れて働く人と、同じ1枚を見る

1自分の作業日を、自分で決められる

  • 担当タスクを週間カレンダーで表示し、ドラッグ&ドロップで作業日を移動(スマホはタップ操作)
  • 見込み時間の入力・完了操作・「この日は終日不可 / ○時間だけ可」の稼働申告も本人から
  • デザイン系の作業は、案件登録時に自動で担当者へ割り当て

2社内ボードと同じデータを共有

  • 社内から入れた予定も、本人が動かした予定も同じ1つのボードに反映
  • 二重管理・言った言わないが起きない
  • 本人が使っているTODOリストの内容もボードに表示し、日付に配置できる
背景: リモートのデザイン担当は他業務との兼ね合いで納期が読みにくいという課題がありました。管理を強めるのではなく、本人が予定を置ける場所を用意して共有する方向で解決しています。

HOW WE BUILT IT

AIとの開発が、うまく回った5つの理由

1いきなり作らせない

調査 → 方針の提示 → 承認 → 実装の順を毎回徹底。「何を作るか」を人間が決め、「どう作るか」をAIに任せる分担にしました。

2必ず動作確認と証跡を出させる

実装後は開発用のパソコンで動かして確認し、画面のスクリーンショット付きで報告してもらう。目で見て納得してから次へ進みます。

3ルールを文書に書いておく

開発の進め方・本番反映の手順をプロジェクト内の文書に明文化。AIが毎回同じ手順を守るので、作業がブレません。

4本番反映は固定の型で

「承認 → 反映 → 本番機でダブルクリック」の一本道に固定。事故が起きにくく、誰でも同じ操作で更新できます。

5社員へのお知らせづくりまで自動化

毎週月曜に配っている社員向けの「社内システムお知らせ(A4)」は、その週の開発履歴からAIが自動作成しています。作った機能を現場に伝えるところまで含めて仕組み化したことで、機能が使われないまま埋もれることがなくなりました。
