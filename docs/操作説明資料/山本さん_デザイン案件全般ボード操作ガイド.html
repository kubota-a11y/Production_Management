✏️ 修正指示が来たとき（2026-08-07 から・いちばん変わったところ）

デザインは一度で決まらず、提出 → お客様確認 → 修正指示 → 再提出を何回か繰り返してから 位置・大きさの確認に進みます。この往復をボタン1つで回せるようにしました。

操作

  1. 「確認」段階のカードを押してモーダルを開く
  2. 「✏️ お客様から修正指示が来たとき」の欄にメモを書く（任意）
    例: 背番号を大きく、袖のロゴは白に　／　画像で伝えたいときは下の「デザインラフ」に添付
  3. ✏️ 修正で鈴木さんへ戻す を押す → 確認ダイアログでOK

③確認 — 4つのステップで進めます

モーダルの「確認の進み具合」を、やりとりが進むたびに切り替えてください。

ステップ状態
1. お客様へ確認連絡社内が動く番 → 今日やることに出ます
2. お客様の返事待ち待ち。7日を超えると催促として今日やることに戻ります
3. 位置・大きさの調整社内が動く番 → 今日やることに出ます
4. 最終確認の返事待ち待ち。OKをもらったら「入稿・製造」へ進めます

※ 途中で修正指示が来たら、ステップを進めずに「✏️ 修正で鈴木さんへ戻す」を使ってください。

デザインラフの渡し方

鈴木さんは会社の共有ドライブを見られません。ラフや修正指示の画像は、カードモーダルの 「デザインラフ」欄に添付してください。鈴木さんのカードに「🖼 ラフ」のリンクが出て、そこから開けます。

対応形式は JPG / PNG / PDF / HEIC / WebP / GIF。1ファイル15MBまで・一度に5件まで。添付するとカードに「ラフ◯件」と出ます。

製造の準備項目を選ぶ

デザイン案件全般は登録時に準備項目を選びません（登録時点は版下データを作る工程のため）。 案件が「④ 入稿・製造」に進んだときに、製造（三浦さん管轄）の項目をここで選びます。

  1. カードに ⚠️ 準備項目 未選定 が付き、今日やることに「製造の準備項目を選ぶ」が出る
  2. カードを開いて「製造の準備項目」欄のチェックボックスから必要な項目を選ぶ
  3. 「選んだ項目を登録する」を押す → 週間スケジュールボードで製造の段取りに使えるようになります

※ 紙媒体（入稿で完了）タイプは製造を通らないので、この欄は出ません。

🔶 CARVE案件

鈴木さんがCARVEで受けている紙媒体の案件です（カードに紫の枠が付きます）。作業段階は ラフアップ→写真入れアップ→修正アップ→入稿の4段階。モーダルの「🔶 CARVEの作業段階」から切り替えられます（本人も切り替え可）。

CARVE案件は鈴木さんの画面で下にまとめて表示されます。「日付が未定のタスク」の中で 「🔶 CARVE案件」の見出しから下にグループ化され、HiYOSHiの案件と混ざりません。
