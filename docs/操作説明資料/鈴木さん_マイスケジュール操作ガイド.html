やることは3つだけ——①予定を組む　②進んだら更新する　③稼働できない日を伝える。 ここで動かした予定は社内の週間スケジュールボードにそのまま出るので別途の報告は要りません。URLはご自身専用です。

画面の並び（2026-08-19 に変わりました）

パソコンでは左に「🗓 今週の予定」、右にタスク一覧（📥 と 📝）が並び、右側はスクロールしても画面に残ります（スマホは従来どおり縦並び）。 右の3つの見出しはクリックで開閉でき、閉じていても件数（見出し横の数字）は見えます。 最初は「日付が未定のタスク」と「CARVE案件」が閉じた状態で開き、開け閉めは端末が覚えます。

ブロック中身
🗓 今週の予定月〜日の日付カード。ここにタスクを置いて「その日にやる」を決めます。稼働の申告もここから
📥 日付が未定のタスク社内から届いた案件の作業。CARVE案件は下の「🔶 CARVE案件」に分かれています
📝 TODOリスト社員用TODOスプレッドシートの「進行中」だけが自動で出ます（未着手は出ません）

① 週のはじめ：今週の予定を組む

  1. 「📥 日付が未定のタスク」の見出しをクリックして開き、「📝 TODOリスト」とあわせてひととおり見る（CARVE案件は中の「🔶 CARVE案件」を開く）
  2. 各カードの「日付を選ぶ」でやる日を決める（日付カードへドラッグでも可）
  3. 見込み時間（h）を入れる — 日カードの「◯h / 6h」で詰まり具合が見えます。超えて赤字になったら入れすぎです。日付プルダウンの「残り◯h」でも空き具合が分かります
  4. 稼働できない日・短い日は「⚙ 稼働変更」で先に申告する
  5. その日の仕事の種類を「🎨 デザイン」「📋 デザイン関連業務」で表明する（もう一度押すと解除）

※ 来週以降に置きたいときは「次週 →」で表示を切り替えてから日付を選びます。

② 日々：進めながら更新する

  • 校正が進んだら 初校 修正 校了 を押して状態を更新する
  • CARVE案件は4段階のプルダウンも進める
  • 作業が終わったら「完了」にチェック → 社内へ自動で伝わります
  • 予定がずれたら日付プルダウンで別の日へ。白紙に戻すなら「↩︎ 未定に戻す」
「初校提出」を完了にすると、その案件のカードは画面から消えます。 社内（山本さん）の確認ターンに移ったためで、正常な動きです。 修正が出たら、山本さんが戻した時点でまた「日付が未定のタスク」に現れます。

③ 修正が戻ってきたとき（2026-08-07 から）

デザインは一度で決まらないのが普通なので、「提出 → お客様確認 → 修正指示 → 再提出」の往復が 仕組みとして入りました。山本さんが「修正で戻す」操作をすると、次の状態でカードが戻ってきます。

戻ってきたときの状態意味
「日付が未定のタスク」に再登場前に入れた予定日はクリアされています。改めて、やる日を決め直してください
🔁 修正◯回目 が付く何往復目かが自動で数えられます（社内のボードにも同じ数字が出ます）
✏️ 修正指示のメモ山本さんが書いた指示。画像があれば「🖼 ラフ」のリンクから開けます
校正バッジが「修正」に自動で切り替わります。必要なら手で押し直してかまいません
完了チェックが外れているもう一度「初校提出」を完了にすれば、また社内の確認に回ります

この往復は何回でも回せます。修正が終わって位置・大きさの確認までOKになると、案件は次の工程へ進みます。

④ 稼働できない日を伝える

日付カードの「⚙ 稼働変更」から3つが選べます。

選択肢使うとき
稼働なし（終日）その日は作業できない。日カードが「稼働なし」になります
時間帯を指定短い日。開始〜終了を入れると稼働時間が自動計算されます
通常に戻す申告を取り消して、いつもの勤務時間に戻します
間に合わなそうなときは、分かった時点ですぐ動かす＋伝える。 ①ボードでタスクを後ろの日へ動かす → ②朝会かLINEでひとこと。 早く分かれば納期の再調整やお客様への先回り連絡ができます。申告にペナルティはありません。

困ったとき

こんなときどうする
案件のカードが見当たらないその案件が「制作」以外の段階にいる可能性が高いです（社内の確認中など）。自分の番になれば自動で出ます。急ぐときは山本さんへ
「📝 TODOリスト」自体が見当たらない見出しが折りたたまれているか、上の「日付が未定のタスク」を開いたままで下に隠れています。「日付が未定のタスク」の見出しをクリックして閉じると、すぐ下に出ます
TODOが出てこないスプレッドシートの状態が「進行中」になっているか確認してください。未着手・振り分け待ちは表示されません（反映まで最大1分）
タスクが1件も見当たらない見出しの横の数字が0でなければ、折りたたまれているだけです。見出しをクリックして開いてください
TODOが二重に見えるシートに同じ文言の行が複数あると1件にまとめられます。別々の仕事なら「◯◯①」「◯◯②」のように名前を分けてもらってください
日付を決めたTODOが未定に戻ったシート側でタスク名が書き換えられたときに起こります。名前で紐づけているためです。ボードで日付を入れ直してください
「通信エラー」と出る電波状況を確認して画面を再読み込みしてください。操作は保存されていないので、やり直しで大丈夫です
