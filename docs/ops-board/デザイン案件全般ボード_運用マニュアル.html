山本さん・鈴木さん向け

このボードの目的は「いま誰の番で案件が止まっているか」を全員が見える状態にすることです。 これまで口頭やチャットで伝えていた「ステータス変更したのでよろしく」「完了したのでよろしく」という報告は、 ボードが自動で通知するので不要になります。 山本さんと鈴木さんが実際に手を動かし、三浦さんと久保田がその流れを確認します。

段階が自動で進むところ

きっかけ結果
鈴木さんが準備項目「初稿提出」を完了②制作 → ③確認 へ自動で進む
鈴木さんが「外注用デザインデータ作成」を完了③確認 → ④入稿・製造 へ自動で進む
鈴木さんが「入稿完了」を完了（紙媒体のみ）⑤請求 へ自動で進む
HiBoardで「📦 納品済み」を押す⑦納品 へ自動で進む

※ 上記以外の移動は、山本さんがカードをドラッグ&ドロップして動かします。

バトンタッチは自動で通知されます

担当が切り替わると、Google Chat の「デザイン案件」スペースに自動でメッセージが届きます。 たとえばこのような内容です。

🎨【○○ユニフォーム】制作のバトンが渡りました → 鈴木さん
✅【○○ユニフォーム】初稿が提出されました → 山本さん: お客様へ確認連絡
↩️【○○ユニフォーム】修正依頼で制作に戻りました → 鈴木さん
「よろしくお願いします」の連絡はもう不要です。 通知が来ていない = まだ自分の番ではない、と考えて大丈夫です。 確認の細かいステップを動かしたときなど、担当が変わらない操作では通知は飛びません。

案件には2つの進行タイプがあります

タイプ流れ
加工まで（標準）
衣類・ユニフォームなど		 上の①〜⑦をすべて通ります
📄 紙媒体・入稿で完了
ポスター・チラシなど		 ②制作から始まり（山本さんのブリーフ・ラフを飛ばす）、お客様の最終OK後に鈴木さんが入稿したら⑤請求へ。請求書を発行して完了です。検品・納品は通りません
登録時に「初稿の納期」「入稿の納期」を分けて入れられます

紙媒体はさらに「HiYOSHi からの依頼」と「🔶 CARVE で受けている案件」に分かれます。 CARVE案件はイレギュラーなので、ボード上では紫の枠が付いて目立つようになっています。

山本さん編 — ボードの使い方

🗂 デザイン案件全般ボード
HiBoard ヘッダーの「🗂 デザイン案件全般」から開きます

画面は上下2つに分かれています

📌 今日やることいま自分が手を動かす案件だけがカードで並びます。まずここを空にすることを目指してください。カードを押すと操作画面が開きます
🗂 案件パイプラインすべての案件が7つの列に並びます。カードをつまんで別の列に落とすと段階が変わります（前にも後ろにも動かせるので、差し戻しも同じ操作です）

この画面に案件を載せる・外す

新しく登録するときボード左上の「➕ 新規案件」を押すと、チェックが入った状態で登録画面が開きます。保存するとこの画面に戻ります
既にある案件を載せるHiBoard一覧ビューのその案件の行にある「🗂 全般へ」ボタンを押します
載せる必要がなかったカード右上の「✕」を押します。案件そのものは消えません（一覧ビューには残ります）
内容を直したいカードを開いて「✎ 案件を編集」。納期・数量・アイテム名など全部変えられます
アイテム名を入れておいてください。（例: ドライTシャツ / az50018 半袖ポロシャツ） カードに 🏷 のタグで表示され、何を作る案件かが一目で分かります。 ホームページのご注文フォームから入った案件は自動で表示されるので入力不要です。

①ブリーフ・ラフ — 鈴木さんへ渡すまで

  1. 依頼内容を確定させます（あいまいなまま渡さないのがいちばん大事です）
  2. カードを開いてデザインラフを添付します。1ファイル15MBまで、一度に5件まで
  3. カードを「制作」の列へドラッグ → 鈴木さんに自動で通知が飛びます
鈴木さんは会社のNASを見られません。 ラフや参考画像は必ずカードに添付してください。添付すると鈴木さんのマイスケジュールボードに 「🖼 ラフ」のリンクが出て、そこから開けるようになります。

③確認 — 4つのステップで進めます

カードを開くと「確認の進み具合」が出ます。やりとりが進むたびに次へ切り替えてください。

1お客様へ確認連絡 … 初稿をお客様へ送る自分の番
2お客様の返事待ち … 送った後、返事を待つお客様待ち
3位置・大きさの調整 … 返事をもとに直して、もう一度お客様へ確認自分の番
4最終確認の返事待ち … OKをもらったら「入稿・製造」へ進めるお客様待ち
1と3（自分の番）は「今日やること」に出ます。 2と4（お客様の返事待ち）は普段は出ませんが、返事がないまま7日を過ぎると催促として自動で戻ってきます。 お客様へ送ったら必ず2や4に切り替えてください。切り替えを忘れると、催促のタイミングがずれてしまいます。

※ 修正が必要になったら、カードを「制作」の列へ戻せば鈴木さんに修正依頼として通知が飛びます。

⑤請求 → ⑥検品 → ⑦納品 → 完了

  • 納品まで済んだら、納品カードの「納品済み・完了にする」チェックを入れて締めます
  • 紙媒体（入稿で完了）の案件は、請求カードの「請求済み・完了にする」チェックで締めます
  • 完了した案件は画面から消えます（「完了した案件も表示する」で確認できます）

鈴木さん編 — いつもの画面だけで完結します

🎨 マイスケジュールボード
これまでと同じ、ご自身専用のURLです

鈴木さんが使う画面は、これまでどおりマイスケジュールボードだけです。 社内のボードを開く必要はありません。作業カードの出方と、完了チェックを押したときに何が起きるかが変わりました。

依頼が来たときの流れ

  1. Google Chat に「制作のバトンが渡りました」と通知が届きます
  2. マイスケジュールボードに作業カードが出ます（「日付が未定のタスク」に入ります）
  3. カードに「🖼 ラフ: ファイル名」のリンクがあれば、そこから山本さんの下絵を開けます
  4. これまでどおり、日付を選んで自分の予定に入れてください
会社のNASを開く必要はありません。 山本さんからのラフや参考画像は、すべてこのリンクから見られるようになっています。 見当たらない・開けないときは山本さんへお知らせください。

完了チェックが「次の人への連絡」になります

準備項目の完了チェックを押すと、案件が自動で次の段階へ進み、次の担当者へ通知が飛びます。

完了にする項目起きること
初稿提出 案件が「確認」へ進み、山本さんへ「初稿が提出されました」と自動通知。山本さんがお客様へ確認します
外注用デザインデータ作成 案件が「入稿・製造」へ進みます。この案件のカードはマイボードから消えます
入稿完了
紙媒体の案件だけに付きます		 案件が「請求」へ進み、山本さんへ「入稿が完了しました」と自動通知。カードはマイボードから消えます
「完了したのでよろしくお願いします」の連絡は不要です。 チェックを押した時点で、システムが山本さんへ伝えています。

納期は工程ごとに出ます

紙媒体の案件は「初稿の納期」と「入稿の納期」が別々に設定されています。 カードにはその工程の納期が出るので、表示されている日付をそのまま目標にしてください。

紙媒体でも、最初に出るカードは「初稿提出」の1枚だけです。 「入稿完了」のカードは、お客様のOKが出て案件が「入稿・製造」に進んでから出てきます。 最初から2枚並んで迷うことはありません。

カードが消えたら、自分の手を離れたということ

案件が「入稿・製造」に進むと、その案件の作業カードはマイスケジュールボードから自動で消えます。 入稿が済んだ後は加工の工程に入るため、鈴木さんの作業ではなくなるからです。 修正が必要になって差し戻された場合は、また出てきます。

紙媒体（ポスター等）の案件だけは例外です。 入稿作業そのものが鈴木さんの仕事なので、「入稿・製造」の間もカードは表示され続けます。 「入稿完了」にチェックを入れると消えます。

変わらないこと

  • 稼働の申告（この日は何時から何時まで）はこれまでどおりです
  • タスクの日付移動、見込み時間の入力もこれまでどおりです
  • 社員用TODOリストの連携もそのままです

最後に — 2人で共有しておきたいこと

山本さんへ

  • 渡す前に依頼内容を確定させ、ラフを添付する
  • お客様へ送ったらステップを切り替える
  • 「今日やること」を空にすることを目安に

鈴木さんへ

  • 完了チェックが連絡そのもの。押し忘れると次が動きません
  • 間に合わないと分かった時点で早めに一報を
  • ラフが見当たらないときは遠慮なく確認を

※ 使い方で迷ったら、HiBoardの「📖 使い方」ガイドの「デザイン案件を回す」の章にも同じ内容が載っています。 仕組みへの要望・使いにくい点は久保田までお知らせください。
